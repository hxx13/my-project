申领物品页面 — 最佳设计方案

基于 Impeccable 产品 UI 品质标准 + Bento 令牌体系。对比当前版本 → 目标版本。

一、当前版本问题诊断（5 类关键缺陷）

🔴 当前问题

  • 硬编码颜色：badge 用 bg-red-500，违反 Bento 令牌规则
  • 字体阶梯过碎：10/11/12/13/14/15/20px 七种字号，无统一比例
  • 卡片信息扁平：名称/副标题/库存/操作挤在同一行，视觉权重无区分
  • 组件缺态：加减按钮无 hover/active/focus 态；提交按钮 loading 时只是 opacity-50
  • 空态无引导：空申领栏只显示"申领物品栏为空"，不教用户下一步做什么

🟢 保留的优点

  • 三栏布局（分类 | 物品网格 | 申领栏）功能结构合理
  • 响应式 Grid repeat(auto-fill, minmax(280px, 1fr)) 正确
  • 骨架屏加载态方向正确
  • "提个建议"入口有温度

三、组件级别改进清单

01 分类侧栏

  • 宽度 180→200px（中文 4 字+ 不截断）
  • 每项加 物品数量 badge
  • 激活态：全背景色 + 左侧 3px 圆角指示条（非 side-stripe 反模式）
  • hover 态：背景微变

02 物品卡片

  • 封面 48→56px，无图时显示物品首字（有温度）
  • 副标题 单行截断（卡片高度一致）
  • 库存改为胶囊标签（充足/紧张/售罄）
  • 操作区用 分割线 与信息区隔离
  • hover: 阴影微抬 + 边框色变

03 步进器

  • 完整七态：default / hover / focus / active / disabled / loading / error
  • + 按钮用 --student-primary 填充
  • 数量为 0 时隐藏 − 和数字（更干净）
  • 售罄态：按钮置灰 + cursor-not-allowed

04 申领栏（右侧栏）

  • 关闭按钮改用 X 图标（非 × 字符）
  • 物品项加 缩略图 + 规格标签
  • 空态：图标 + "选择你需要的物品加入申领栏" + 跳转按钮
  • 底部固定总数 + 提交按钮，始终可见

05 加载态

  • 分类侧栏：6 条骨架（非空白）
  • 物品网格：6 张骨架卡片（已有，保留）
  • 右侧申领栏：骨架占位

06 空态 & 错误态

  • 物品为空 → 图标 + "本分类暂无物品" + "切换分类" 引导
  • 申领栏为空 → "请从左侧选择物品加入申领栏"（教用户怎么用）
  • 加载失败 → 错误提示 + "重新加载" 按钮

四、Impeccable 品质检查清单（方案内置自检）

✅ 已通过项

  • 所有颜色走 --student-* / --app-color-* 令牌，零硬编码
  • 字号阶梯：12/13/14/15px（比例 1.125-1.15），克制不碎
  • 正文行宽在卡片内 ≤75ch，Grid 自适应
  • 步进器七态完整
  • z-index 语义阶梯：page → sidebar → overlay → modal
  • 无 AI 反模式（无侧边竖线、无渐变文字、无玻璃态、无眉标、无编号段）
  • Skeleton 加载 + 教育性空态
