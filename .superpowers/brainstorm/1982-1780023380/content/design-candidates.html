🎨 Notion 风格

紫色主调 + 海军蓝 Hero + 粉彩卡片 — 像一本温暖的笔记本。丰富的 pastel 色卡（桃/玫瑰/薄荷/薰衣草/天空/奶油），插图驱动，信息密度高。学生对 Notion 天然熟悉。

适合学生的点

  • 年轻人熟悉的 Notion 美学
  • 丰富的 pastel 色彩系统
  • 高信息密度卡片布局

风险

  • 色彩过于丰富，数据展示易混乱
  • 与现有代码风格差异大

⚫ Vercel 风格

黑白精确 + Mesh 渐变装饰 + Geist 字体 — 极简工程美学。100px 胶囊按钮、堆叠阴影卡片、代码编辑器式暗色面板。与项目现有的 twin 设计令牌高度重叠。

适合学生的点

  • 极致清晰，数据展示最佳
  • 与现有 CSS 变量体系高度兼容
  • 响应式断点体系完善

风险

  • 过于"开发者工具"感
  • 缺少温度，可能显得冰冷

🌙 Linear 风格

深色画布 + 薰衣草蓝唯一强调色 + 极度克制 — 软件工艺感。不使用渐变、不使用第二种彩色、产品截图主导页面。最深的暗色系统。

适合学生的点

  • 极致的克制和高级感
  • 暗色模式天然护眼
  • 单一强调色避免视觉噪音

风险

  • 纯暗色对学生日常使用偏暗
  • 缺少明亮/活力感
  • 与教职工后台 Sci-Fi 主题混淆

推荐策略

我的推荐：以 Vercel 为主骨架 + Notion 的色彩温度 + Airbnb 的圆角友好度 = 混合体系

理由：

  • Vercel 作为骨架 — 其黑白精确体系与项目现有的 --twin-* CSS 令牌高度兼容，响应式断点完整，数据表格/表单/卡片组件规范齐全
  • Notion 的温度注入 — 引入 3-4 个 pastel 强调色（薄荷绿、天空蓝、薰衣草紫）作为功能模块的视觉区分，使仪表盘更活泼
  • Airbnb 的友好度 — 借用其圆角尺度（rounded.lg 14px 卡片 + rounded.full 搜索框），降低工具感，提升亲和力
  • 与教职工后台的隔离 — 教职工用 Sci-Fi 暗色 + 深色侧边栏；学生用亮白画布 + 柔和 pastel + 浅色侧边栏。两套视觉体系零交叉。
