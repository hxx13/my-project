需新增/修改的模块

层级 模块 说明
数据库 personnel 表 + personal_pin 字段 存储 6-8 位数字密码 (bcrypt 哈希)
数据库 学生中心预置数据表 为未注册 userid 预建 student 账号数据
后端 API 批量预写入接口 扫描 personnel 表 → 生成学生中心预置数据
后端 API PIN 设置/验证/修改 setPin / verifyPin / changePin
后端 API 特殊通道登录 userId + PIN → JWT token
前端组件 NumericKeypad 可复用数字键盘组件 (设置/验证模式)
前端组件 BizOverlayShell 快捷业务覆盖层容器 (预留框架)
前端改造 UiverseProfilePopup 底部新增"进入学生中心"按钮
前端改造 AdminPersonnelPage 学生 tab 新增 PIN 状态列
