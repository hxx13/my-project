路由设计

路由 用途 备注
/admin/knowledge 知识花园主壳（默认浏览视图） 替代现有 5 条路由
/admin/knowledge?view=graph 知识图谱视图 query param，可分享

/admin/knowledge?page=42 直接打开某篇文档 深链接 + 可分享
/admin/knowledge?edit=42 编辑某篇文档 编辑器占中间面板
/admin/knowledge/new 新建文档 query param 进入编辑模式

✅ 这一节的设计要点

  • 只有 1 条路由，视图切换纯 state 驱动，零页面跳转
  • URL query params 保持深链接可分享（?page=42, ?view=graph）
  • 左侧目录 + 标签筛选，右侧大纲 + 反向链接
  • 顶部 tab 栏：文档浏览 / 知识图谱 / 生长记录 + 新建按钮
  • 面包屑 + 上/下一篇导航（芋道风格）
