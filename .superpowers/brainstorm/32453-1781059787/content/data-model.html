第六节：数据模型 & API 变更

相比现有设计文档的增量变更 — 只列本次新增/修改的部分

数据库变更（1 个 ALTER）

变更 SQL 说明
ADD COLUMN ALTER TABLE knowledge_pages
ADD COLUMN tags JSON DEFAULT '[]'		 标签数组，如 ["Spring","ORM"]

knowledge_categories 和 knowledge_history 表不变，现有字段已满足所有需求。

新增 API（6 个端点）

方法 路径 用途
GET /knowledge/graph 图谱数据 {nodes, edges}，支持 categoryId/tag 筛选
GET /knowledge/pages/{id}/backlinks 反向链接列表（手动[[wikilink]]+自动扫描合并）
POST /knowledge/graph/rebuild 触发全量 wikilink 扫描 + 引用分析重建
GET /knowledge/timeline 时间线数据，支持 type/author/since 筛选，分页
GET /knowledge/tags 标签云 [{name, count}]，支持 categoryId 筛选
GET /knowledge/stats 仪表盘统计：文档总数/分类数/标签数/最近更新时间

修改现有 API（1 个）

端点 变更
PUT /knowledge/pages/{id} 请求体新增 tags 字段；保存时自动扫描 content_md 中的 [[wikilink]] 并更新引用关系

前端路由变更

变更 内容
删除 5 条路由 /admin/knowledge/category/:categoryId
/admin/knowledge/page/:pageId
/admin/knowledge/page/:pageId/edit
/admin/knowledge/page/:pageId/history
/admin/knowledge/new
保留 1 条路由 /admin/knowledge
删除 4 个页面 AdminKnowledgePageDetail / EditorPage / HistoryPage — 并入 KnowledgeShell

新增后端 Service 逻辑

组件 职责
WikilinkScanner 正则扫描 content_md 中的 [[title]]，返回引用列表
ReferenceAnalyzer 全量分析：基于标题关键词共现 + 分类相似度自动发现潜在引用
GraphService 构建 nodes+edges，合并手动+自动引用，计算引用权重
