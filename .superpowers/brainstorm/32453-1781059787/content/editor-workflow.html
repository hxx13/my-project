## 概述
MyBatis 是一款优秀的持久层框架，它支持自定义 SQL、
存储过程以及高级映射。

## Maven 依赖
```xml
<dependency>
  <groupId>org.mybatis</groupId>
  <artifactId>mybatis-spring-boot-starter</artifactId>
</dependency>
```

参见 [[Spring Boot 配置]] 和 [官方文档](https://mybatis.org)。

保存流程

  1. 前端：content_md → 本地预览（可选）
  2. 提交：PUT /api/admin/knowledge/pages/{id}
  3. 后端：flexmark MD→HTML → jsoup 清洗 → 写入 content_html
  4. version+1，插入 history 快照
  5. 前端：invalidate queries → 自动刷新目录树+大纲+反向链接
  6. 保存成功 → 自动切换到浏览视图

编辑器行为规则

  • 有 content_md → 开 Markdown 编辑器
  • 仅有 content_html → 开 HTML 简易编辑器（contenteditable）
  • 新建文档默认 Markdown 模式
  • slug 从标题自动生成中文拼音，可手动修改
  • [[wikilink]] 实时高亮 + 自动补全已有文档标题
  • Ctrl+S 快捷保存
