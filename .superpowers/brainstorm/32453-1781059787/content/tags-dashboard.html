状态切换逻辑

中间面板的三种状态 — 由有无选中文档 + 当前视图决定
条件 中间面板显示 典型场景
无选中文档 + 浏览视图 仪表盘（统计+标签云+卡片网格） 首次进入 /admin/knowledge
选中文档 + 浏览视图 文档正文 + 大纲 + 反向链接 点击目录/卡片/搜索结果
任一状态 + 图谱视图 知识图谱（左侧筛选+画布） 点击顶栏"知识图谱"
任一状态 + 时间线视图 生长记录（左侧筛选+时间线） 点击顶栏"生长记录"
进入编辑模式 编辑器（中间切换，左右栏变） 新建/编辑文档

标签数据模型

标签存为 knowledge_pages.tags JSON 数组字段，无需新建关联表（MVP 简洁方案）：

ALTER TABLE knowledge_pages ADD COLUMN tags JSON DEFAULT '[]';
-- 示例: ["Spring", "ORM", "后端"]

标签统计 API：

GET /api/admin/knowledge/tags → { tags: [{name:"Spring", count:42}, ...] }

后续可升级为独立 knowledge_tags 表 + 多对多关联，但 MVP 用 JSON 字段足够。
