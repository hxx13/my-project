数据来源

利用现有 knowledge_history 表，无需新建表：

  • 每个 INSERT 到 history 表 = 一条时间线条目
  • type 字段推断：version=1 → "新建"，summary 含"回滚" → "回滚"，source=imported → "导入"，其余 → "编辑"

新增 API：

GET /api/admin/knowledge/timeline?limit=50&type=all&author=&since=

交互行为

  • 点击条目 → 切换到文档浏览视图，打开对应文档
  • 左侧筛选即时生效（前端过滤已加载数据，30条后重新请求）
  • 滚动到底部自动加载更多（无限滚动）
  • 可折叠日期分组
