✅ 极客风设计原则

  • 白底阅读 + 暗色代码 = 专业开发者文档的黄金组合
  • 等宽字体用于所有"技术感"元素：slug、版本号、标签、时间戳
  • 终端绿 #3fb950 点缀在状态指示、加载动画、提示文字
  • 代码块用 GitHub Dark 主题（项目已有 highlight.js 兼容）
  • 暗色图谱画布 = 夜空中的知识星系
  • 动效克制：150-250ms，不花哨，不拖慢

🎯 与现有项目的关系

  • 复用项目现有 CSS 变量（--app-color-*），不建独立主题
  • 代码高亮复用现有 highlight.js 配置
  • GSAP 动画复用 gsap-react / gsap-scrolltrigger
  • 新增少量专用 CSS 变量：--knowledge-code-bg, --knowledge-graph-bg
  • 仪表盘卡片网格用 Tailwind grid，不引入额外库
