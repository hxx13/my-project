三个开源引擎对比

筛选条件：MIT 许可 · 小数据量(<500行) · 宽列(30-100) · 混合编辑器 · 无公式 · 需导入导出

A

revo-grid ⭐ 推荐

MIT · ~80KB · 虚拟 DOM · React 原生支持

B

glide-data-grid

MIT · Canvas 渲染 · 超高性能 · 适合复杂自定义单元格

C

@tanstack/react-table 增强

MIT · 已安装 · 零新依赖 · 需自行构建 Excel 交互层

关键维度打分

维度 A revo-grid B glide-data-grid C tanstack 增强
宽列 (30-100) ✅ 水平虚拟滚动 ✅ Canvas 原生快 ⚠️ 需手动优化
预制编辑器 (下拉/日期/复选框) ✅ 内置 column types ⚠️ 需手写 drawCell ⚠️ 需手写 column meta
勾选行 ✅ 内置 rowSelection ⚠️ 需手写 ✅ 内置
Excel 导入/导出 ✅ 插件 + 后端 FastExcel ⚠️ 需手写映射 ⚠️ 手写 sheetjs 映射
包体积 ~80KB ~47KB 0（已安装）
Tailwind/shadcn 适配 ✅ CSS变量主题 ⚠️ Canvas 独立主题 ✅ 完全控制
类 Excel 交互 (选区/复制粘贴/撤销) ✅ 内置 ⚠️ 部分内置 ❌ 需全部自建

方案 A 适配架构预览 (revo-grid)

SmartSheet 组件架构
SmartSheet (封装层)
├── RevoGrid React Wrapper
│ ├── 列定义 → ColumnConfig[]（预制模板）
│ ├── 行数据 → RowData[]
│ ├── 编辑器注册表（dropdown/date/checkbox/textarea）
│ └── 选区管理 + 复制粘贴
├── Toolbar（自定义）
│ ├── 新建表格 / 打开 / 保存
│ ├── 导出 Excel → @/api/excel/export
│ ├── 导入 Excel → @/api/excel/import
│ └── 撤销/重做
├── 统计面板 (侧边/底部)
│ ├── 列统计 (count/sum/avg/unique)
│ └── 图表联动 (可选 recharts 可视化)
└── Tailwind 主题桥接
└── CSS 变量注入 → revo-grid 主题变量
