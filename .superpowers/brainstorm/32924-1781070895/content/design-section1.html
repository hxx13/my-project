设计 Part 1：数据模型 & 架构

先定数据结构和组件树，后面再细化交互和统计面板

核心概念：两张表

数据库模型
-- ① 表格定义表：存表格的元信息
smartsheet_definition
├── id (PK)
├── name (表格名称)
├── description (描述)
├── columns_config (JSON) ← 列定义（类型/选项/校验）
├── created_by / updated_by
└── created_at / updated_at
───────────────────────────
-- ② 数据行表：存每一行的实际数据
smartsheet_row
├── id (PK)
├── sheet_id (FK → smartsheet_definition)
├── row_index (行序号)
├── cell_data (JSON) ← 每个单元格的值 {"col_key":"val"}
└── created_at / updated_at

💡 用 JSON 存列定义和单元格数据 → 列的数量/类型完全动态，不改表结构就能加列

列类型系统（columns_config JSON）

每个列可以配置为以下类型之一：

类型交互方式配置项
select下拉单选options: ["选项A","选项B",...]
multi-select多选标签options: [...]
date日期选择器format: "YYYY-MM-DD"
checkbox勾选框—
number数字输入min / max / decimal
text自由文本maxLength / placeholder
user人员选择— (对接现有 PersonnelSearchDropdown)

前端组件树

组件层级
SmartSheetPage (路由页)
├── SmartSheetToolbar
│ ├── 表格切换 Dropdown（多表格场景）
│ ├── [新建] [导入Excel] [导出Excel]
│ └── [添加列] [添加行] [撤销][重做]
├── SmartSheetGrid (核心：revo-grid 封装)
│ ├── 列头右键菜单（编辑列/删除列/排序）
│ ├── 行勾选框 → 批量操作栏
│ ├── 单元格编辑器注册表
│ └── 选区 / 复制粘贴 / 键盘导航
└── SmartSheetStatsPanel (可折叠侧边栏)
├── 选中列统计（计数/去重/求和/空值）
└── 简易图表（可选 recharts 柱/饼图）
