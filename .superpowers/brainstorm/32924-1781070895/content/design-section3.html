REST API 设计

方法路径说明
GET/admin-api/smartsheet/sheet/page表格列表分页
POST/admin-api/smartsheet/sheet新建表格（含列定义）
GET/admin-api/smartsheet/sheet/:id获取表格详情 + 列定义
PUT/admin-api/smartsheet/sheet/:id更新表格（名称/列定义）
DELETE/admin-api/smartsheet/sheet/:id删除表格
GET/admin-api/smartsheet/:sheetId/rows获取所有行数据
POST/admin-api/smartsheet/:sheetId/row新增一行
PUT/admin-api/smartsheet/:sheetId/row/:rowId更新单行（单单元格编辑）
DELETE/admin-api/smartsheet/:sheetId/row/:rowId删除行
POST/admin-api/smartsheet/:sheetId/rows/batch批量新增（导入用）
GET/admin-api/smartsheet/:sheetId/export导出 Excel（FastExcel）
POST/admin-api/smartsheet/:sheetId/import导入 Excel（接收文件）
GET/admin-api/smartsheet/:sheetId/stats列级统计（计数/求和/去重/空值率）

异常路径覆盖

场景处理
导入列数 > 100拒绝 + 提示 "最大支持 100 列"
导入行数 > 500拒绝 + 提示 "单表最大 500 行"
列类型变更冲突已有数据不兼容 → 警告 "将清空该列已有数据"
并发编辑冲突乐观锁（updated_at 版本号），冲突时提示刷新
JSON 列定义非法后端校验 JSON Schema，400 + 错误详情
Excel 格式不支持仅接受 .xlsx/.xls/.csv，其余 400
删除有数据的表格确认弹窗 → 级联删除所有行
导入列映射失败未匹配列显示为"跳过/创建新列"，不让静默丢弃
