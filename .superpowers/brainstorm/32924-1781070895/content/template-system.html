🔄 统一引擎架构

新建表格时选模板 → 自动生成列定义。底层用同一套存储和渲染。

📋 选择模板
→
生成 columns_config
→
存入 smartsheet_definition
→
revo-grid 渲染
→
按 layout_mode 切换视图
layout_mode: "matrix" | "table" | "checklist" | "calendar"
// 每种模式自带默认列配置模板，用户可在此基础上增删改

📊 数据模型扩展

字段类型说明
layout_modeENUM(matrix/table/checklist/calendar)新增：控制渲染布局
row_entity_sourceJSON (nullable)新增：行实体来源。null=手动管理；{type:"table", id:xx} = 引用其他表数据（如机房列表）
columns_configJSON已有，结构不变。每列: {key, label, type, options, ...}
template_idVARCHAR (nullable)新增：从哪个模板创建的，便于升级模板时提示

🏗️ 按日巡查表 → SmartSheet 迁移路径

📌 迁移方案：不删旧代码，新增适配层

阶段 1：SmartSheet 引擎完成 Matrix 模式 → 新建一张"设施巡查"模板表验证功能
阶段 2：在 AdminFacilityMaintenancePage 中嵌入 SmartSheet 组件（替代现有 DailyInspectionPanel 中的自绘 table）
阶段 3：旧 DailyInspectionPanel 代码保留并存运行 → 确认功能对齐后，切换路由指向新组件
阶段 4：旧代码标记 @deprecated，下个版本清理

💡 后端复用现有的 fm_daily_inspection_sheet 表不动，SmartSheet 通过 row_entity_source 引用 FM 模板和机房数据，兼容旧协作逻辑
