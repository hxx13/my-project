申领单状态机 · 物品级可选流程

每件物品可配置简单流程或复核流程，审核人按 账号 + 权限 双重指派

🟢 简单流程（默认）
DRAFT 草稿
⬇ 学生提交
PENDING 待审核
⬇ 审核人审批
↙                 ↘
REJECTED 已拒绝   APPROVED 已通过
                            ⬇ 出库
FULFILLED 已出库
⬇ 学生确认领取
RECEIVED 已完成
🟡 复核流程（敏感物品）
DRAFT 草稿
⬇ 学生提交
PENDING 待初审
⬇ 初审人审批
FIRST_OK 初审通过
⬇ 复审人审批
APPROVED 已通过
⬇ 出库
FULFILLED 已出库
⬇ 学生确认
RECEIVED 已完成

🔑 审核人指派模型

物品配置层（教职工上架时设置）：

  • workflow_type：SIMPLE / DUAL_REVIEW
  • reviewer_ids：指定审核人账号 ID 列表（初审人）
  • second_reviewer_ids：复审人账号 ID 列表（仅 DUAL_REVIEW）

运行时校验：审核人必须同时满足：

  • ✅ 账号在物品的 reviewer_ids 中（或 second_reviewer_ids）
  • ✅ 拥有 STAFF 或更高角色权限
  • ❌ 不满足任一条件 → 不可审核该物品的申领
