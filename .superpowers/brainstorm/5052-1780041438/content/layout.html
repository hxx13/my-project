学生活跃度统计 - 页面布局方案

左侧：课题组筛选 + 指标概览 | 右侧：成员排名表 + 时段热力图

A

上下分区布局（推荐）

顶部：课题组筛选栏 + 时间选择器 + KPI摘要卡片（总人数/总进出/日均时长/最近活跃）

中间：成员活跃度排名表（可排序列：进出次数/总时长/日均频次/最近活跃）

底部：选中成员的时段热力图（横轴=小时，纵轴=星期，颜色=进出密度）

B

左右分栏布局

左侧栏（窄）：课题组树形选择器 + 成员列表

右侧主区：选中成员的详细活跃度卡片（大图表 + 指标数字）

适合逐个查看成员详情，但对排名对比不友好

C

仪表盘布局

顶部筛选栏（一行搞定：课题组下拉 + 时间范围 + 导出按钮）

下方为多卡片网格：每个成员一张活跃度卡片（头像+名字+核心指标+迷你趋势图）

类似 GitHub 贡献者页面，直观但成员多时滚动较长
