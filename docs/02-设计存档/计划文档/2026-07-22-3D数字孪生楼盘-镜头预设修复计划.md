## 根因详解

### U7: 只能配置 3/6 个值

**数据模型** ([useStore.ts:55-60](frontend/src/features/digital-twin-3d/store/useStore.ts#L55-L60))：

```
CameraPreset {
  camOffset:    [x, y, z]   ← 相机位置 = globalCenter + camOffset
  targetOffset: [x, y, z]   ← 注视目标 = globalCenter + targetOffset
}
```

**UI 只能控制 camOffset**：三个滑块（仰角/方位/距离）通过球坐标反算控制相机位置，但注视目标固定不变。`targetOffset` 的修改途径仅有鼠标中键平移——用户看不到数值，无法精确输入。

### U8: 刷新后偏移 — 架构性根因

**根因链**：

```
CameraPresets 缺少 floorMode 维度
         ↓
stacked / exploded / staircase 三模式共用同一套预设
         ↓
在 exploded 模式下调整好镜头 → 保存到唯一的 "1F" 槽位
         ↓ 刷新页面
floorMode 重置为 'stacked'（不持久化）
explodeConfig 恢复了但 setFloorMode 未调用
         ↓
相机飞到 gc + camOffset（相同绝对位置 ✅）
但楼层从 "展开" 变回 "堆叠"，模型 Y 轴位置变了
         ↓
→ 偏移
```

**关键代码**：

| 位置 | 问题 |
|------|------|
| [useStore.ts:186](frontend/src/features/digital-twin-3d/store/useStore.ts#L186) | `floorMode: 'stacked'` 写死，不持久化 |
| [useStore.ts:63-66](frontend/src/features/digital-twin-3d/store/useStore.ts#L63-L66) | `CameraPresets` 类型只有 `floors` + `overview`，无 `mode` 维度 |
| [useStore.ts:194](frontend/src/features/digital-twin-3d/store/useStore.ts#L194) | `focusOnFloor` 强制 `floorMode = 'stacked'` |

**6 个假设验证结果**：

| # | 假设 | 结论 |
|---|------|------|
| H1 | targetOffset 捕获意外状态（ViewControls 按钮/鼠标平移/Effect 覆写） | ✅ 设计缺陷 |
| H2 | camOffset 和 targetOffset 用了不同的 globalCenter | ❌ 排除（同一行代码同一 gc 引用） |
| H3 | 保存/恢复时 globalCenter 不同 | ❌ 排除（同 GLB 确定性） |
| H4 | UI 显示用当前 gc 算绝对位置，与保存时的 gc 可能不同 | ✅ 混淆放大器 |
| H5 | **floorMode 不持久化 + 预设无 mode 维度** | ✅ **主因** |
| H6 | globalCenter 被重复叠加 | ❌ 排除 |

## 架构修正方案

### 核心变更：CameraPresets 增加 floorMode 维度

**当前（一层）**：

```typescript
CameraPresets {
  floors: Record<string, CameraPreset>  // { '1F': {...}, '2F': {...} }
  overview: CameraPreset
}
```

**修正后（两层）**：

```typescript
CameraPresets {
  stacked: {
    floors: Record<string, CameraPreset>
    overview: CameraPreset
  }
  exploded: {
    floors: Record<string, CameraPreset>
    overview: CameraPreset
  }
  staircase: {
    floors: Record<string, CameraPreset>
    overview: CameraPreset
  }
}
```

**逻辑**：切换 floorMode → 自动切换到对应模式的预设集。每个模式拥有完全独立的 5 个预设（1F/2F/3F/4F/overview），互不干扰。

### 配套变更：floorMode 持久化

```
刷新前: floorMode = 'exploded' → restore 'exploded' → floors 展开 → 用 exploded 预设集
刷新后: floorMode = 'stacked'  → restore 'stacked'  → floors 堆叠 → 用 stacked 预设集
```

`explodeConfig` 已经持久化了，`floorMode` 也需要同样处理。

### 配套变更：targetOffset 编辑控件

即使加了 mode 维度，用户仍需要能**精确控制 6 个值**。在面板中为 `targetOffset` 增加 X/Y/Z 数字输入。

#### P0.1 类型定义

```typescript
type FloorMode = 'stacked' | 'exploded' | 'staircase';

type CameraPresets = Record<FloorMode, {
  floors: Record<string, CameraPreset>;
  overview: CameraPreset;
}>;

const DEFAULT_PRESETS: CameraPresets = {
  stacked:   { floors: {}, overview: { camOffset: [0,30,60], targetOffset: [0,8,0] } },
  exploded:  { floors: {}, overview: { camOffset: [0,30,60], targetOffset: [0,8,0] } },
  staircase: { floors: {}, overview: { camOffset: [0,30,60], targetOffset: [0,8,0] } },
};
```

#### P0.3 floorMode 持久化

```typescript
const LS_FLOOR_MODE = 'dt3d-floor-mode';

function loadFloorMode(): FloorMode {
  try {
    const raw = localStorage.getItem(LS_FLOOR_MODE);
    if (raw === 'exploded' || raw === 'staircase' || raw === 'stacked') return raw;
  } catch { /* */ }
  return 'stacked';
}

// store 初始化
floorMode: loadFloorMode(),

// setFloorMode 持久化
setFloorMode: (mode) => {
  try { localStorage.setItem(LS_FLOOR_MODE, mode); } catch { /* */ }
  set({ floorMode: mode, focusedFloor: null });
},
```

#### P0.4 focusOnFloor 保持当前模式

```typescript
// 旧：
set({ focusedFloor: name, floorMode: 'stacked', selectedNode: null });

// 新：
set({ focusedFloor: name, selectedNode: null });  // 不改变 floorMode
```

#### P0.6 旧格式迁移

```typescript
function loadCameraPresets(): CameraPresets {
  try {
    const raw = localStorage.getItem(LS_CAMERA);
    if (raw) {
      const p = JSON.parse(raw);
      // 检测旧格式：顶层有 overview 字段 → 单层结构
      if (p.overview && !p.stacked) {
        // 迁移：旧数据放入 stacked，其他模式用默认值
        return {
          stacked: { floors: p.floors || {}, overview: p.overview || DEFAULT_OVERVIEW },
          exploded: { floors: {}, overview: DEFAULT_OVERVIEW },
          staircase: { floors: {}, overview: DEFAULT_OVERVIEW },
        };
      }
      // 新格式：直接使用
      return p;
    }
  } catch { /* */ }
  return DEFAULT_PRESETS;
}
```

## localStorage 结构变更

### 旧格式（将被迁移）

```json
{
  "floors": { "1F": { "camOffset": [0,8,15], "targetOffset": [0,2,0] } },
  "overview": { "camOffset": [0,30,60], "targetOffset": [0,8,0] }
}
```

### 新格式

```json
{
  "stacked": {
    "floors": { "1F": { "camOffset": [0,8,15], "targetOffset": [0,2,0] } },
    "overview": { "camOffset": [0,30,60], "targetOffset": [0,8,0] }
  },
  "exploded": {
    "floors": {},
    "overview": { "camOffset": [0,30,60], "targetOffset": [0,8,0] }

    "floors": {},
```

## 备注

- **globalCenter X/Z 恒为 0**：`recomputeGlobalBounds` 中的 XZ 质心计算恒得 0。camOffset/targetOffset 的 XZ 分量本质上是绝对世界坐标。此次不重构（避免影响兼容性），可作为后续简化项。
- **damping 问题降级**：OrbitControls damping 在短动画后的残留动量是真实存在的，但与"偏移"问题无关。如果未来用户报告"滑块调节后画面还在滑动"，再单独处理 damping。
- **`focusOnFloor` 不再强制 stacked**：这是行为变更。聚焦楼层时保持当前 floorMode，让用户在 exploded 下也能聚焦单层查看。
