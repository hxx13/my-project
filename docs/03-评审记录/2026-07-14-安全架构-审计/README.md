## 攻击链路速览

```
Phase 1 — 信息收集（30s）
  └─ /swagger-ui.html → 完整 API 蓝图 + 小程序首页 → 有效学号

Phase 2 — 初始入侵（30s）
  └─ NS6: POST /special-channel/set-pin → 获得有效 JWT

Phase 3 — 权限提升（1min）
  └─ NS1: jwt_mock_token_USERID → SUPER_ADMIN

Phase 4 — 数据收割与持久化
  └─ S4 模拟任意人员 + NS4/S2 全量密码解密 + S9 WebSocket 监听
```

**最严重攻击链可在约 5 分钟内从零外部知识达到完全系统控制。**

---

> **核心教训**: 配置扫描工具（grep/SAST）可发现 S1-S22 类问题，但无法发现 NS1-NS35 类逻辑漏洞。所有 `if` 语句中的安全决策必须逐行审查——这是任何自动化工具无法替代的。
