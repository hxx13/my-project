**整改措施**：

### 2.2 任意文件上传（⚠️ 已有审计 S18，需升级优先级）

### 2.4 Swagger UI 目录泄露（✅ 已有审计 NS7）

**渗透测试确认**：`http://10.127.139.31:8080/swagger-ui/index.html`（内网 IP）可公开访问。

**代码核实**：

- `pom.xml:89-92`：`springdoc-openapi-starter-webmvc-ui` 2.6.0 已引入
- `OpenApiConfig.java`：创建 OpenAPI bean，无 `@Profile` 限制
- `WebMvcConfig.java:34-61`：`ApiAuthInterceptor` 路径中**未包含** `/swagger-ui/**` 和 `/v3/api-docs/**`

**整改措施**：

| 序号 | 操作 | 优先级 | 关联审计 |
|:---:|------|:---:|------|
| SW1 | `OpenApiConfig.java` 添加 `@Profile("!prod")`，生产环境 Bean 不加载 → 内网和外网均不可访问 | **P0** | NS7 |

> 该修复已在审计 P0 第 2 项，预计 2 分钟完成。`@Profile("!prod")` 方案从 Java 进程层面禁用，**同时覆盖内网 IP 和外网域名**，比 nginx 层屏蔽更彻底。

### 2.7 后端服务器直接暴露公网（🆕 新增）

**渗透测试确认**：

1. 从公开接口 `GET /api/public/runtime-config` 获取到后端配置信息
2. 后端服务器 `47.101.61.184:8080` 可从公网直接访问（绕过 nginx）

**代码核实**：

| 位置 | 当前状态 |
|------|---------|
| `RuntimeConfigController.java:16,30` | `/api/public/runtime-config` 完全无认证 |
| `WebMvcConfig.java:43-44` | `/api/public/**` 排除在拦截器外，无认证、无限流 |
| `NotificationSettingsService.java:185-201` | `getPublicRuntimeConfig()` 返回所有 `is_public=1` 的配置项 |
| `HttpsExtraPortRegistry.java` | 暴露 `cameraHttpsPort`（备用 HTTPS 端口） |
| 网络层 | 后端 Java 进程绑定在公网 IP `47.101.61.184`，端口 8080 对公网开放 |

**这是什么问题？**

当前架构：

```
公网用户 → nginx (HTTPS:443) → 后端 Java (47.101.61.184:8080)
                ↑                        ↑
           有 SSL/限流/安全头          公网 IP，端口直接可达
```

攻击者**绕过 nginx 直接打后端**：`http://47.101.61.184:8080/swagger-ui/index.html`。nginx 的所有安全策略（HTTPS、限流、安全头、IP 过滤）全部失效。

**换成内网 IP 后是否还会出现？**

**不会。** 正确架构：

```
公网用户 → nginx (公网IP:443 + 内网IP:网卡) → 后端 Java (10.x.x.x:8080，纯内网)
              ↑                                      ↑
         双网卡，同时通公网和内网                    只有内网 IP，公网不可达
```

后端换成内网 IP 后，`http://10.x.x.x:8080/` 只有内网机器能访问，公网完全无法触及。

**整改措施**：

| 序号 | 操作 | 优先级 |
|:---:|------|:---:|
| BE1 | ~~网络层：将后端服务器从公网 IP 迁移到内网 IP~~ | **暂不执行** |
| BE2 | **应用层**：`RuntimeConfigController` 返回数据前过滤敏感 key（`cameraHttpsPort`、`network.*` 等），即使无意中将敏感 key 标记为 `is_public=1` 也不会泄露。此修复在公网和内网环境都有效 | **P1** |
| BE3 | **审计 `sys_system_config_def` 表**：检查所有 `is_public=1` 的配置项，确认无不必要暴露的 key。`network.*` 类配置项一律不设为 public。此修复在公网和内网环境都有效 | **P0** |

> **BE1 暂不执行说明**：将后端切到内网 IP 是网络架构变更，仅在切换到内网部署后才能生效。当前生产环境仍为公网部署，暂时不执行此变更。BE2/BE3 是代码/数据层修复，在公网环境下同样有效，照常执行。

**涉及文件**：

- `src/main/java/com/example/demo/modules/notification/controller/RuntimeConfigController.java`
- `src/main/java/com/example/demo/modules/notification/service/NotificationSettingsService.java`
- `src/main/java/com/example/demo/common/config/HttpsExtraPortRegistry.java`
- `src/main/java/com/example/demo/common/config/WebMvcConfig.java`
- 服务器防火墙/安全组规则（运维层面）
