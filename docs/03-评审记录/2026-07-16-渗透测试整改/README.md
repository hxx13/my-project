## 背景

2026-07-15 对生产环境 `https://aroultra.shsmu.edu.cn` 进行渗透测试，发现弱口令、任意文件上传、越权、信息泄露等安全问题。本目录记录针对性的整改计划。

## 与已有审计的关系

7/14 安全架构审计已通过四轮代码审查发现 57 项缺陷。本次渗透测试是对生产环境的实际验证：**大部分发现已被审计覆盖**，同时发现了 **7 个有效新增缺口**（其中 5 个阻断级）。越权 URL 经核实为假阳性（测试者使用 admin 账号），强制改密暂时搁置。
