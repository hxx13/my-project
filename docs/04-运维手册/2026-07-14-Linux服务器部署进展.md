## 二、本会话中修复的代码问题

所有修改已提交至 `feature/miniprogram-telemetry-ui-20260704` 分支（commit `f79a9586`，12 个文件，+176/-1592 行）。

### 代码修改清单

| 文件 | 改动 | 原因 |
|------|------|------|
| `schema.sql` | 新建 | 提前建核心表，在 DataSource 初始化时（早于所有 bean @PostConstruct）执行 |
| `application.properties` | 加 `spring.sql.init.mode=always` | 启用 DataSourceInitializer 自动执行 schema.sql |
| `EmbeddedTwinSystemCoreDdlBootstrap.java` | 实现 `InitializingBean`，新增 `afterPropertiesSet()` | DDL 在 bean 初始化早期执行（早于其他 bean 的 @PostConstruct） |
| `MpCloudProxySecretFilter.java` | `init()` 方法加 try-catch | 容错：表不存在时降级为默认值（空 secret → 放行所有请求） |
| `DebugToggleService.java` | `init()` 方法加 try-catch | 同上，降级为默认开关值 |
| `DahuaAuthService.java` | `reloadCredentials()` 方法加 try-catch | 同上，降级为默认凭证 |
| `TwinCardMappingService.java` | `reloadCache()` 方法加 try-catch | 同上，降级为空缓存 |
| `TwinFreezeConfigService.java` | `ensureDefaultRow()` 方法加 try-catch | 同上，降级为跳过列检查 |
| `AroService.java` | `forceInitialLogin()` 方法加 try-catch | 同上 |
| `WebMvcConfig.java` | CORS `allowedOriginPatterns` 加 `"https://aroultra.shsmu.edu.cn"` | 修复浏览器登录 403 `Invalid CORS request` |
| `pom.xml` | 加 `maven.build.timestamp.format` + `finalName` | JAR 文件名带时间戳（格式 `demo-YYYYMMDD-HHmmss.jar`），避免构建覆盖旧包 |
| `db/bootstrap-system-config.sql` | 新建 | sys_system_config / sys_system_config_def / sys_system_config_audit 三表的 DDL |

> **注**：`schema.sql` 和 `db/bootstrap-system-config.sql` 包含相同的 `CREATE TABLE IF NOT EXISTS` 语句。这是**故意的双层保障**——schema.sql 由 Spring DataSourceInitializer 执行（最早），bootstrap-system-config.sql 由 StartupRunner 执行（第二次机会）。`IF NOT EXISTS` 保证幂等，不冲突。

## 四、部署中遇到的坑（供后续参考）

| # | 现象 | 根因 | 解法 |
|---|------|------|------|
| 1 | JAR 启动秒退，仅一行 Logback WARN | 未指定 `--spring.profiles.active`，logback-spring.xml 所有 appender 都在 springProfile 内 | 加 `--spring.profiles.active=prod` |
| 2 | JAR 启动报 `Unknown or incorrect time zone: 'Asia/Shanghai'` | MariaDB 缺少时区数据 | `mysql_tzinfo_to_sql /usr/share/zoneinfo \| mysql mysql` |
| 3 | 多个 bean 启动时 `Table 'twin_system.sys_system_config_def' doesn't exist` | DDL 执行时机晚于 @PostConstruct（StartupRunner vs bean init） | 双层方案：schema.sql 提前建表 + 6 个 bean 加 try-catch |
| 4 | 登录 `Invalid CORS request` 403 | CORS 未放行生产域名 | 加 `https://aroultra.shsmu.edu.cn` |
| 5 | 数据导入 `utf8mb4_0900_ai_ci` 报错 | MariaDB 不支持 MySQL 8.0 排序规则 | `sed` 替换为 `utf8mb4_unicode_ci` |
| 6 | 外键约束错误阻止建表 | dump 中建表顺序问题 | `mysql --force` 强制跳过 + 使用 `--no-create-info` 导数据 |
| 7 | Docker/Podman 拉镜像超时 | 校园网屏蔽 Docker Hub | 放弃 Docker MySQL，直接用裸机 MariaDB |
| 8 | SSH 直连 `10.127.139.31` 超时 | VLAN 隔离（同网段 `10.127.x.x` 但不同 VLAN） | 仅通过堡垒机 SSH |

## 六、快速操作参考

### 本地构建

```bash
cd frontend && npm run build && cd ..
mvn clean package -DskipTests
# 产物：target/demo-YYYYMMDD-HHmmss.jar（时间戳格式）
```

### 服务器部署

```bash
# 上传 JAR 到 /home/aroadmin/（通过堡垒机 SFTP）
# SSH 终端：
sudo rm -f /opt/twin/app/demo-*.jar
sudo mv /home/aroadmin/demo-*.jar /opt/twin/app/
pkill -f 'demo-.*\.jar'
nohup java -jar /opt/twin/app/demo-*.jar --server.port=8080 --spring.profiles.active=prod --spring.datasource.password=SuperAdmin@2026 > /tmp/jar.log 2>&1 &
# ⚠️ --spring.profiles.active=prod 不可省略，否则 Logback 无 appender 直接退出
```
