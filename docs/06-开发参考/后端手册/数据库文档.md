# 数据库文档

友情提示：

最新版本的代码，已经移除“数据库文档”功能。原因是，该功能比较小众，可能只有极少数的用户需要~

如果你系统里需要，可以参考 ff0c12c（后端）、ff52769（前端） 把代码复制、粘贴回来。

`yudao-module-infra` 的 DatabaseDocController 类，基于 Screw 工具，生成数据库表结构的文档。

访问 \[基础设施 -> 数据库文档\] 菜单，可以查看项目的数据库文档。如下图所示：

> 📷 *基础设施 -> 数据库文档*

关于 Screw 的使用讲解，可见 《芋道 Spring Boot 数据表结构文档 》 文章。
