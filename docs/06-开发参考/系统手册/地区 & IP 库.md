# 地区 &amp; IP 库

`yudao-spring-boot-starter-biz-ip` 业务组件，提供地区 & IP 库的封装。

##  1. 地区

AreaUtils 是地区工具类，可以查询中国的省、市、区县，也可以查询国外的国家。

数据来源：

原数据来自 Administrative-divisions-of-China 项目；由于该项目已停止更新（数据停留在 2023 年版本），现已切换为兼容 AreaCity-JsSpider-StatsGov 的 csv 数据：

-   当前版本：`2025.251231.260403`（2026-04-03 发布）
-   整合数据源：国家地名信息库 2025-12-31、腾讯地图行政区划 2025-11-19、高德地图行政区划（采集当天）
-   csv 转换脚本：yudao-cloud#247

它的数据最终整理到项目的 area.csv 文件。每一行的数据，对应 Area 对象。代码所示：

```
public class Area {

    /**
     * 编号
     */
    private Integer id;
    /**
     * 名字
     */
    private String name;
    /**
     * 类型
     *
     * 枚举 {@link AreaTypeEnum}
     * 1 - 国家
     * 2 - 省份
     * 3 - 城市
     * 4 - 地区, 例如说县、镇、区等
     */
    private Integer type;

    /**
     * 父节点
     */
    private Area parent;
    /**
     * 子节点
     */
    private List<Area> children;
    
}
```
