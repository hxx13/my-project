## 层次四：Web 界面合规检查（web-interface-guidelines）

Vercel 出品的代码级 UI 检查规则，用于审查已写好的 UI 代码。

- **源码**: [github.com/vercel-labs/web-interface-guidelines](https://github.com/vercel-labs/web-interface-guidelines)
- **规则**: 每次审查前从源码拉取最新规则
- **用途**: 验证 UI 代码是否符合 Web 标准（对比度、触摸目标、语义 HTML 等）

## 如何使用

### 层次一 → 先选方向
打开 [8-anchors 预览](previews/ai-secretary-8-anchors.html)，选一个 vibe。

### 层次二 → 再挑品牌
在 getdesign.md 上浏览你觉得对味的品牌预览，每个都有：
- 完整色板 + CSS 变量
- 字体层级表
- 按钮/卡片/表单组件
- 间距和阴影系统
- 响应式断点

### 层次三 → 最后审查
代码写完后，用 web-interface-guidelines 检查合规性。
