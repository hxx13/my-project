# 近期更新速览 (2026.06)

**主题**
- 新增暗色/亮色/科幻三种主题，一键切换
- 暗色模式覆盖扫描端和学生端，后台页面不受影响

**物资管理**
- 新增图片卡片式物资浏览，支持灯箱大图预览
- 新增拖拽和粘贴上传图片
- 新增库存锁定功能，锁定库存在学生端不可见
- 新增库存流水审计，每次出入库可追溯
- 新增审计数据 Excel 导出
- 新增审批状态自动消息通知
- 学生端新增物资申请、进度追踪、新物品需求提交

**Web 与小程序图片互通**
- Web 后台现在能直接查看小程序云存储的图片
- 无法直接展示的云图片会提示用户去小程序查看，不再显示裂图

**扫描弹窗**
- 新增 10 套暖色调随机配色方案
- 新增性别差异化配色（男生暖色 / 女生冷色）
- 优化通知弹出逻辑：仅在离场时弹出，在场时不打扰
- 优化面板宽度和视觉层次，去掉了黑色遮罩

**SmartSheet 电子表格**
- 新增条件格式（按单元格值自动变色）
- 新增查找替换功能
- 新增 CSV 导入导出

**学生端**
- 新增房间卡片、笼格查询、AI 档案入口
- 新增 ARO 设备绑定
- 页面切换新增动画过渡

**知识库**
- 重做为全屏图谱浏览界面

**其他优化**
- 弹窗不再遮挡顶栏
- 下拉菜单不再被侧边栏裁切
- 右键菜单定位修正
