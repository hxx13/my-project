# 系统功能更新公告 (2026.06)

本次更新覆盖主题系统、物资管理、图片互通、扫描弹窗、SmartSheet、管理后台、学生端及知识库共八大模块，以下是各模块的详细说明。

---

## 1. 暗色与亮色主题系统

主题切换已完成底层统一改造。原先 Bento 与 Twin Chrome 两套主题各自维护，现在合并为单一的 ThemeSwitcher 组件，一键切换亮色/暗色/科幻三种模式，切换状态同步到右键菜单。

### 核心改动

- 亮色/暗色/科幻三模式主题切换器已挂载到管理后台顶栏和 DebugNav 调试坞
- `.dark` 类的作用范围严格限定在 TwinLayout 和扫描弹窗 Portal，不会意外影响到管理后台页面
- 完整的 `.theme-scifi` 语义令牌映射：所有 Sci-Fi 主题的颜色值通过 `--app-color-*` 令牌体系驱动，不再有独立硬编码
- 7 个调试页面（CardMapping / CardStatus / Heatmap / Order / Prediction / Personnel / Table）全部完成从 `slate-x` / 硬编码色值到 `--app-color-*` 令牌的迁移

### 组件迁移清单

扫描端组件（ProfileHeader / ActionButtons / UiverseProfilePopup / ScanAccessNoticeOverlay / ViolationNoticeBanner）全部接入令牌体系。管理后台的 AdminHomePage 图标改为 registry 驱动的 homeTone 渐变配色，白底图标在彩色背景上清晰可见。

---

## 2. 物资管理页面与图片加载

物资模块经历了从前端到后端的完整重构，核心目标是让图片成为一等公民、打通管理员与学生之间的数据通道。

### 管理端

- 物资卡片改为图片优先布局：每件物品展示缩略图，点击可打开灯箱大图预览
- 图片上传支持拖拽粘贴（Ctrl+V 粘贴剪贴板图片），导入体验对标现代文件管理工具
- 物资管理页整合了 CRUD 编辑弹窗、入库、库存调整、回收站，全部操作在一个页面完成
- 库存锁定机制：锁定中的库存对学生端不可见，解锁后自动回流
- `showStockQty` 开关控制是否向学生端展示实时库存数量
- 审批流程配置（SIMPLE / DUAL_REVIEW）在学生端自动隐藏，避免概念泄漏

### 审计系统

- 三标签页审计面板：个人审计 / 分组审计 / 物品审计
- 物品库存流水审计：记录每次入库、出库、调整，通过 JOIN 查询关联申请人所属分组
- 服务端筛选：支持按申请人、分组、日期范围过滤，数据量大的场景下不会拖慢前端
- Excel 导出：审计数据可一键下载为 Excel 文件

### 统计与通知

- 管理端统计面板展示审批通过率和库存预警
- 按分组统计接口 (`stats/by-group`) 供图表消费
- 物资状态变更（提交/审批/驳回/撤回）自动推送消息通知，消息系统已完整接入

### 学生端

- 学生物资页面复用管理端同一数据源，不再有独立 API 调用链，保证数据一致性
- 学生可查看物品预览（含库存数量）、提交申请、追踪审批进度
- 需求通道：学生可以提交新物品需求，管理员审核后可转为正式物资

## 3. Web 端与小程序图片互通

云端存储的图片文件使用 `cloud://` 格式的 FileID，浏览器无法直接读取。本次更新建立了一条桥接通道，使得同一张图片在 Web 管理后台和微信小程序两端都能正常展示。

### 技术方案

- `isCloudFileId(url)` 识别云存储 FileID
- `webImageSrc(url)` 自动将 `cloud://` 地址代理到 `/api/upload/proxy-image`，后端读取云文件并返回浏览器可渲染的图片流
- `dualImageSrc({ publicUrl, wechatFileId })` 优先使用 CDN 公网地址，无公网地址时回退到微信 FileID

### 用户界面

- 工单和物资图片缩略图组件 `WorkorderImageThumb` 根据 URL 类型自动切换显示模式：浏览器可访问的 http(s) 地址直接渲染 `<img>` 标签并支持灯箱预览；`cloud://` 地址显示"小程序查看"提示卡片
- 图片加载失败时自动回退为占位提示，不会出现裂图空白
- `DualImage` 组件覆盖所有双端图片展示场景

## 4. 扫描弹窗视觉升级

扫描端的弹出界面经历了一次全面的配色和层次重构，从单一样式变为十套暖色调配色方案，每次随机选取，视觉上不再单调。

### 配色体系

- 10 套暖色调方案 (Peach / Amber / Orange / Rose / Coral / Honey 等)，通过 CSS 变量注入
- 弹出面板五个视觉层级：背景底板、浮起面板、内部卡片、环形高光、性别强调色
- 性别差异化：男生使用暖色边框和图标，女生使用冷色系，色彩与管理员图标渐变保持同一色域 (400/500 级)
- 各组件独立调色：ProfileHeader 桃色装饰条、AIPredictionCard 珊瑚色调、StudentEntryCard 蜂蜜色调、公告岛玫瑰色边框

### 交互细节

- 违规/未绑定/公告通知面板仅在用户状态为 OUTSIDE 时自动弹出，INSIDE 时不打扰
- 通知面板移除黑色遮罩层，对话框直接浮起，配合渐变背景和辉光球增加深度感
- 面板宽度扩容至 44rem，内容不再拥挤
- 所有扫描端浮层组件统一接入 SCAN_MODAL_LAYER_PROPS 滚动守卫

## 5. SmartSheet V2 电子表格

SmartSheet 从基础表格升级为具备完整电子表格能力的数据工具。

### 新增功能

- 条件格式规则面板：支持基于单元格值的背景色、文字色、对齐方式自动变化
- 查找替换对话框：Ctrl+F 唤起，匹配项高亮，支持单个替换和全部替换
- CSV 导入对话框：三步导入流程（选择文件 → 预览映射 → 确认导入），导出文件带 UTF-8 BOM 确保 Excel 直接打开不乱码
- FormatContext 上下文贯通：单元格数据模型扩展为 `{v, fmt}` 结构，格式信息在渲染链路中全程保留
- 完整工具栏：包含格式刷、对齐、条件格式、查找替换、导入导出等全部操作入口

### 底层改进

- JSON 字符串单元格值自动解析（`normalizeCellValue`），修复空白单元格显示问题
- 列宽拖拽调整、行高优化、单元格点击编辑
- 条件格式与数据解耦，`cf-bg` CSS 类独立管理

## 6. 管理后台首页改版

管理后台首页卡片从固定网格改为响应式紧凑布局。

- 卡片采用 Bento 设计系统的暖色调表面配色，图标使用 registry 驱动的 homeTone 渐变
- 图标渐变统一在 400/500 色阶范围内，白底图标在彩色背景上清晰可辨
- 最小高度和响应式网格保证不同屏幕尺寸下布局不崩
- CommandPalette 搜索框点击区域修复，不再被其他元素遮挡
- 图标中文标签通过 LABEL_MAP / PATH_TITLE_MAP 覆盖英文 model 名称

## 7. 学生端 Phase 2

学生门户在 Phase 1 的基础上扩展了多个功能模块。

- 统一登录：学生通过扫码或账号密码登录，进入统一门户
- 房间卡片：展示学生绑定的房间信息，含房间号、楼栋、容量状态
- 笼格管理：学生可查看自己分配的笼格编号和位置
- AI 档案：接入 AI 预测卡片，展示快捷业务入口和个人中心
- ARO 绑定：管理员可在后台将学生与 ARO 设备绑定
- 学生物资页面：查看可申请物品、提交申请、追踪审批、提交新物品需求
- Dashboard 和房间页添加 GSAP 动画过渡

## 8. 知识库重写

知识库模块经历了一次完整的拆除重建。

- 全文检索和分类浏览统一为沉浸式全屏图谱界面
- 文档和文件夹移动操作统一为 MoveMenu 组件，交互一致
- 图界面优化触控和全高渲染

## 9. 其他改进

- 管理后台所有弹窗统一偏移 `top-16`，不再遮挡顶部导航栏
- 下拉菜单通过 Portal 渲染到 `document.body`，不再被侧边栏 overflow 裁剪
- z-index 全部通过 CSS 变量令牌 `--z-*` 管理，杜绝层级冲突
- 右键菜单定位改为 Portal 渲染，修正鼠标坐标计算
- 回复编辑器适配暗色主题
- SmartSheet 内禁用全局右键菜单，避免与表格自身的右键功能冲突
- 设计文档站新增 326 篇后端开发参考和业务导图工具
