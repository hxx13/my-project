# 系统功能更新公告 (2026.06)

本次更新覆盖主题系统、物资管理、图片互通、扫描弹窗、SmartSheet、管理后台、学生端及知识库共八个模块。

---

## 1. 暗色与亮色主题系统

原先 Bento 与 Twin Chrome 各自维护一套主题切换逻辑，现在合并为单一的 ThemeSwitcher 组件，亮色/暗色/科幻三种模式一键切换，切换状态同步到右键菜单和顶栏。

ThemeSwitcher 已挂载到管理后台顶栏和 DebugNav 调试坞。`.dark` 类的作用范围限定在 TwinLayout 和扫描弹窗 Portal，不会渗透到管理后台页面。`.theme-scifi` 的语义令牌映射全部完成，Sci-Fi 主题下的所有颜色都通过 `--app-color-*` 令牌体系驱动，不再有独立硬编码值。

7 个调试页面（CardMapping / CardStatus / Heatmap / Order / Prediction / Personnel / Table）从 `slate-x` 和裸色值迁移到语义令牌。扫描端的 5 个核心组件（ProfileHeader / ActionButtons / UiverseProfilePopup / ScanAccessNoticeOverlay / ViolationNoticeBanner）同步完成迁移。管理后台首页图标改为 registry 读取 homeTone 生成渐变，400/500 色阶范围保证了白底图标在彩色背景上的辨识度。

---

## 2. 物资管理页面与图片加载

物资模块前后端都经过了重写。图片现在是物资卡片的第一视觉元素，不再藏在详情页深处。

管理端物资卡片采用图片优先布局，每件物品展示缩略图，点击进入灯箱大图预览。上传支持拖拽文件和 Ctrl+V 粘贴剪贴板图片，不用先存到本地再选文件。物资管理页整合了编辑弹窗、入库、库存调整和回收站，同一页面完成全部操作。

库存锁定机制让管理员可以暂扣某些库存，锁定期间学生端不可见，解锁后自动回流。`showStockQty` 开关控制学生端是否看到实时库存数。SIMPLE / DUAL_REVIEW 审批流程配置对学生端自动隐藏。

审计面板分三个标签页：个人审计、分组审计、物品审计。物品库存流水记录每次入库、出库和调整明细，通过 JOIN 关联申请人所属分组。筛选全部在服务端完成，数据量大时不会拖慢前端。审计结果可一键导出 Excel。

统计面板展示审批通过率和库存预警，`stats/by-group` 分组统计接口供图表消费。物资状态变更（提交/审批/驳回/撤回）自动触发消息推送，消息系统已完全接入。

学生端的物资页面和管理端共用同一数据源，不再维护独立的 API 调用链。学生可以预览物品（含库存数量）、提交申请、追踪审批。需求通道允许学生提交新物品需求，管理员审核后可转正为正式物资条目。

## 3. Web 端与小程序图片互通

云存储的图片文件使用 `cloud://` 格式 FileID，浏览器无法直读。这次我们加了一条代理通道，同一张图片在 Web 后台和微信小程序两边都能正常展示。

技术侧做了三件事：`isCloudFileId(url)` 识别云存储 FileID；`webImageSrc(url)` 自动把 `cloud://` 地址代理到 `/api/upload/proxy-image`，后端读取云文件返回浏览器可渲染的图片流；`dualImageSrc({ publicUrl, wechatFileId })` 优先走 CDN 公网地址，没有公网地址时回退微信 FileID。

UI 层由 `WorkorderImageThumb` 统一处理：http(s) 地址直接渲染 `<img>` 标签，点击可灯箱预览；`cloud://` 地址显示"小程序查看"提示卡片，告诉用户到小程序端查看或等待后台同步。图片加载失败自动回退为占位提示，不会出现裂图空白。`DualImage` 组件覆盖所有双端图片展示场景，包括工单详情和通知收件箱。

## 4. 扫描弹窗视觉升级

扫描端的弹出界面从单一样式换成十套暖色调配色方案，每次随机选一套，不同场景看到的配色不同。

配色通过 CSS 变量注入，十套方案覆盖 Peach、Amber、Orange、Rose、Coral、Honey 等暖色系。弹出面板划了五个视觉层级：背景底板、浮起面板、内部卡片、环形高光、性别强调色。性别差异体现在边框和图标颜色上：男生暖色，女生冷色，色调保持在 400/500 色阶，与管理后台图标渐变同一色域。各组件有独立调色：ProfileHeader 桃色装饰条、AIPredictionCard 珊瑚调、StudentEntryCard 蜂蜜调、公告岛玫瑰色边框。

交互上，违规通知、未绑定提醒和公告面板只在用户状态为 OUTSIDE 时自动弹出，INSIDE 时不打扰。通知面板去掉了黑色遮罩层，对话框直接浮起，渐变背景加辉光球提供深度。面板宽度扩到 44rem。所有扫描端浮层统一接入 SCAN_MODAL_LAYER_PROPS 滚动守卫。

## 5. SmartSheet V2 电子表格

SmartSheet 升级为电子表格，增加了条件格式、查找替换和 CSV 导入导出。

条件格式规则面板支持按单元格值自动切换背景色、文字色和对齐方式。查找替换用 Ctrl+F 唤起，匹配项高亮，支持逐条替换和全部替换。CSV 导入分三步：选文件、预览映射、确认导入。导出文件带 UTF-8 BOM，Excel 直接打开不会乱码。单元格数据模型从纯值扩展为 `{v, fmt}` 结构，格式信息在渲染链路里全程保留。工具栏集合了格式刷、对齐、条件格式、查找替换和导入导出入口。

底层方面，JSON 字符串单元格值现在会自动解析（`normalizeCellValue`），之前那些看起来空白的单元格实际上是 JSON 字符串没被展开。列宽可以拖拽调整，点击单元格即进入编辑。条件格式和表格数据解耦，`cf-bg` CSS 类独立管理。

## 6. 管理后台首页改版

首页卡片从固定网格改为响应式紧凑布局。卡片用 Bento 暖色调表面配色，图标走 registry 的 homeTone 渐变，400/500 色阶内白底图标清晰可辨。最小高度和响应式网格保证各屏幕尺寸下布局不崩。CommandPalette 搜索框的点击区域修复，不再被叠层遮挡。图标标签通过 LABEL_MAP 和 PATH_TITLE_MAP 显示中文名。

---

## 7. 学生端 Phase 2

学生门户在 Phase 1 基础上扩展了房间卡片、笼格管理、AI 档案和物资模块。

学生登录后进入统一门户，首页展示绑定的房间信息（房间号、楼栋、容量状态）和分配的笼格编号。AI 档案卡片集合了快捷业务入口和个人中心。后台管理员可将学生与 ARO 设备绑定。物资页面打通了申请、审批追踪和新物品需求提交流程。Dashboard 和房间页加了 GSAP 动画过渡。

---

## 8. 知识库重写

知识库经历了一次完整的拆除重建。全文检索和分类浏览统一为沉浸式全屏图谱界面。文档和文件夹的移动操作统一到 MoveMenu 组件，交互保持一致。图界面优化了触控操作和全高渲染。

---

## 9. 其他改进

- 管理后台所有弹窗统一偏移 `top-16`，不再遮挡顶部导航栏
- 下拉菜单通过 Portal 渲染到 `document.body`，不被侧边栏 overflow 裁剪
- z-index 统一走 CSS 变量 `--z-*` 令牌，避免层级冲突
- 右键菜单改为 Portal 渲染，修正了鼠标坐标计算偏差
- 回复编辑器适配暗色主题
- SmartSheet 内部禁用全局右键菜单，防止与表格自身右键功能打架
- 设计文档站新增 326 篇后端开发参考和业务导图工具
