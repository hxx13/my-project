# 代码格式化

项目的 ESLint 配置文件位于根目录的 [eslint.config.mjs](https://github.com/yudaocode/yudao-ui-admin-uniapp/blob/master/eslint.config.mjs)，基于 [@uni-helper/eslint-config](https://github.com/uni-helper/eslint-config) 进行配置。

项目内集成了以下几种代码校验工具：

- [ESLint](https://eslint.org/)：用于 JavaScript/TypeScript 代码检查
- [Prettier](https://prettier.io/)：用于代码格式化（集成在 ESLint 中）

我们可以使用 IDE 自带的 Linter 功能，实现代码的格式化（自动检查和修复）。

友情提示：

如果你想使用 Prettier 插件，可参考 [《代码格式化（Prettier）》](https://vue3/format) 文档。

##  1. JetBrains 端

参考 [《JetBrains 官方文档》](https://www.jetbrains.com/help/idea/linters.html) 操作即可。

① 【手动修复】右键文件，选择 `Fix ESLint Problems` 即可。如下图所示：

![JetBrains 端 ESLint 自动修复](/knowledge-images/deaabfcbee4c.png)

② 【自动修复】可在 JetBrains 设置界面的 ESLint 选项中，勾选上 `Run eslint --fix on save` 选项，如下图所示：

![JetBrains 端 ESLint 自动修复 - 设置](/knowledge-images/86b1c4e1b88b.png)

之后，保存页面，页面代码自动格式化。

##  2. VS Code 端

参考 [《VS Code 官方文档》](https://code.visualstudio.com/docs/languages/javascript#_linters) 操作即可。

【自动修复】打开 VS Code 配置，搜索 save 后，勾选上 `Format On Save` 选项。如下图所示：

![VS Code 端自动格式化 - 设置](/knowledge-images/90b0522e39f2.png)

之后，保存页面，页面代码自动格式化。
