# 公众号接入

本章节，讲解如果将你的公众号，接入到系统中。步骤如下：

-   第一步，申请公众号（可选）
-   第二步，在系统中，添加公众号账号
-   第三步，在公众号中，配置接入信息

##  1. 配置步骤

本小节，手把手教你如何将公众号接入到系统中。

###  第一步，申请公众号（可选）

友情提示：如果你已经有公众号，可以忽略这一步。

① 如果你还没有公众号，可以申请一个测试帐号。

> 📷 *申请测试账号*

申请地址：微信公众平台接口测试帐号申请

② 申请完成后，获得一个测试号。如下图所示：

> 📷 *测试账号信息*

###  第二步，添加公众号账号

点击 \[公众号管理 -> 账号管理\] 菜单，添加一个公众号账号。如下图所示：

> 📷 *添加公众号账号*

###  第三步，配置接入信息

① 由于公众号通知需要外网地址，可参考 [《内网穿透》](/开发参考/萌新必读/内网穿透.md) 文档，将本地的 48080 端口，转发到外网中。这里，我的域名是 `http://yunai.natapp1.cc`。

② 打开微信公众号界面，填写 URL 和 Token 信息。如下图所示：

> 📷 *填写 URL 和 Token 信息*

点击提交后，看到“配置成功”提示，说明配置成功。
