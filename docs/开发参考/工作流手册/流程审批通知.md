# 流程审批通知

相关视频：

-   22、如何实现工作流的短信通知？

流程（审批）在发生变化时，会发送通知给相关的人。目前有三个场景会有通知，通过短信的方式。

> 📷 *短信通知*

它是通过 BpmMessageService 调用 SmsSendApi 短信 API 所实现，如下图所示：

图片纠错：最新版本不区分 yudao-module-bpm-api 和 yudao-module-bpm-biz 子模块，代码直接合并到 yudao-module-bpm 模块的 src 目录下，更适合单体项目

> 📷 *BpmMessageService*

① 如果想要接入其它通知方式，在 BpmMessageService 调用其它通知的 API 即可，例如说：

-   [《邮件配置》](/开发参考/系统手册/邮件配置.md)
-   [《站内信配置》](/开发参考/系统手册/站内信配置.md)

② 如果想要更多场景的通知，可以考虑基于 [《执行监听器、任务监听器》](/开发参考/工作流手册/执行监听器、任务监听器.md) 实现，在监听器中调用通知 API。
