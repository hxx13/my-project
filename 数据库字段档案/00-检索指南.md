## 六、提取方法（如需重新从源文档提取）

**Excel（.xlsx）**：xlsx 是 ZIP 包。用 Python `zipfile` + `xml.etree` 解析：
1. `xl/sharedStrings.xml` → 共享字符串数组
2. `xl/workbook.xml` → sheet 名列表
3. `xl/_rels/workbook.xml.rels` → sheet 名 → target 映射
4. `xl/worksheets/sheetN.xml` → 每个 `<c>` 单元格，`t="s"` 时值 = 共享字符串索引，否则取 `<v>` 文本

**Word（.docx）**：docx 是 ZIP 包。解析 `word/document.xml`：
- 段落 `<w:p>` 内的 `<w:t>` 拼接 = 段落文本
- 表格 `<w:tbl>` 内 `<w:tr>`/`<w:tc>` = 表格行列

## 七、关键业务结论（换对话快速对齐）

- 核心链路：供体→受体→配型→手术→样本→随访→结局，**移植事件 TX 是枢纽**（样本/检测/随访/用药/病理/麻醉/心脏模块全挂 TX）
- TP 时点 12 个（TP01 术前筛查 ~ TP12 数据锁定），定义「什么字段什么时候用」
- 四级 ID 16 类（DON/RCP/XM/TX/FU/AE/REG/MED/LVL/ANES/PATH/HX/PERF/SMP/TST/RS + ORG）
- 两层架构：字段字典（数据）+ 表单模板（呈现），题型属表单模板层，字段字典不设 control_type
- 代码分层：schema（纯类型）→ store（纯 reducer）→ editor（薄组件）→ components（渲染），拒绝巨石文件
