# 11-字段控件规格

> 状态：**设计态**。本文件定义字段「怎么填」（控件层），补齐 Excel 缺失的 EDC 通用控件能力。控件是「字典字段」和「填写页」之间的桥。

## 一、Excel 现状与缺口

Excel「数据类型」列只有 9 种基础类型（数值82/字符69/枚举52/文本30/日期7/日期时间5/枚举多选2/枚举+数值1/时间1），即「存什么」。**没有定义「怎么填」（控件）**。

全表扫描结论：附件/图片上传、电子签名、重复组、单选/复选区分、计算字段 —— 这些控件能力 Excel 均未提及（仅 2 处「自动计算」暗含）。

## 二、核心设计：data_type ≠ 题型（题型属表单模板层，见 12）

- `data_type`（存什么）→ 决定值落 `crf_record_value` 哪个类型化列，在字段字典层。
- 题型（怎么填）→ 属**表单模板层**（见 12），由用户在设计器自由配置。
- **字段字典不设 control_type**；data_type → 默认题型仅作「生成初始模板时的建议」。

## 三、控件规格（14 类）

| control_type | 适用 data_type | 存储 | UI 形态 | 码表/校验 |
|---|---|---|---|---|
| TEXT_INPUT 单行文本 | STRING/字符 | value_string | 单行输入框 | 长度上限 |
| TEXTAREA 多行文本 | TEXT/文本 | value_text | 多行文本框 | 长度上限 |
| NUMBER 数值 | INTEGER/DECIMAL/数值 | value_int / value_decimal | 数值输入 + 单位后缀 | 范围、精度 |
| DATE 日期 | DATE/日期 | value_date | 日期选择器 | 时点窗口 |
| DATETIME 日期时间 | DATETIME/日期时间 | value_datetime | 日期时间选择器 | 时点窗口 |
| TIME 时间 | TIME/时间 | value_string | 时间选择器 | — |
| SELECT 下拉单选 | ENUM/枚举 | value_string + codelist_item_id | 下拉 | 码表（>5 项） |
| RADIO 单选按钮 | ENUM/枚举 | value_string + codelist_item_id | 单选按钮组 | 码表（≤5 项） |
| MULTISELECT 多选 | ENUM_MULTI/枚举多选 | crf_record_value_item | 多选标签/复选 | 码表 |
| CHECKBOX 复选 | ENUM_MULTI | crf_record_value_item | 复选组 | 码表（≤5 项） |
| CALC 计算字段 | CALC | 不落库（派生） | 只读计算显示 | 表达式（版本化） |
| FILE_UPLOAD 附件上传 | FILE | value_file_id → upload_file_record | 上传 + 文件列表 | 类型/大小限制 |
| REPEAT_GROUP 重复组 | 复合 | 子 record_value 组 | 可增删行表格 | 行数限制 |
| SIGNATURE 电子签名 | 特殊 | crf_signature | 签名面板 | 签署人/角色 |

## 四、Excel 9 类型 → 控件默认映射

| Excel data_type | 默认 control_type | 数量 |
|---|---|---|
| 数值 | NUMBER | 82 |
| 字符 | TEXT_INPUT | 69 |
| 枚举 | SELECT（可改 RADIO） | 52 |
| 文本 | TEXTAREA | 30 |
| 日期 | DATE | 7 |
| 日期时间 | DATETIME | 5 |
| 枚举多选 | MULTISELECT（可改 CHECKBOX） | 2 |
| 枚举+数值 | 复合（数值 + 码表） | 1 |
| 时间 | TIME | 1 |

## 五、需补的控件（Excel 未提及，但业务需要）

| 缺口控件 | 业务对应 | 说明 |
|---|---|---|
| FILE_UPLOAD 附件上传 | 病理报告扫描件、超声影像、基因鉴定报告 | 复用 upload_file_record |
| REPEAT_GROUP 重复组 | D6 每次给药、D10 灌注每3h、随访纵向序列 | 一行多字段可增删行 |
| CALC 计算字段 | D10 血管阻力（自动计算）、冷缺血时间 | 表达式版本化 |
| SIGNATURE 电子签名 | PI/数据管理员签署、病历锁定 | 接 crf_signature |
| RADIO/CHECKBOX 区分 | 枚举选项少的字段 | ≤5 项用单选/复选 |

## 六、落地建议

1. 字段字典（05）不设 control_type，只保留 data_type。
2. 题型由表单模板层（12）配置，复制 AUP 模式为 NHP 专用编辑器，自由选择题型。
3. 附件/重复组/计算/签名 等题型在表单模板层 typeRegistry 提供（Excel 未提及但填写页离不开）。

## 七、数据驱动推断（依据「取值/码表」列，249 字段全量归类）

不用逐个猜，看「取值/码表」列就能推断 control_type：

| 取值/码表 | 推断 control_type | 数量 |
|---|---|---|
| — | 自由填写（按 data_type） | 143 |
| 具体枚举字面值（阴性/阳性、M/F…） | 下拉 / 单选 | 35 |
| 码表XXX | 下拉单选（码表） | 31 |
| 编码规则 / VER-XXX | 自动生成 ID | 16 |
| 外键 / 方案库 / D7版本域 | 关联下拉 | 14 |
| ≥0 / ≥0整数 | 数值 + 范围校验 | 6 |
| 时点表 | 下拉（时点表） | 3 |
| 评分表（待冻结） | 待定 | 1 |

**需「具体问题具体分析」的序列/复合类字段**（取值="—" 但说明暗含序列/重复）：

- D7.02.001 监护时间点（每5-15min序列）、D9.04.002 移植物心率（连续）、D9.04.004 心律失常事件（AE序列）、D9.04.007 超声序列、D10.02.001 灌注参数序列 → **重复组控件**
- D5.01.005 一般状态评分 → 评分控件
- D2.01.004 性别/年龄 → 枚举+数值复合控件
