# 12-表单模板层与连锁关系

> 状态：**设计态（架构定调）**。本文件确立「字段字典」与「表单模板」两层分离，复用 AUP 的表单设计器（aup-template/edit），并定义字段字典 → 表单模板的**连锁关系自动生成**规则。
>
> **纠正 11 的错误**：题型（题目形式/控件）属于「表单模板层」，不属于「字段字典层」。`crf_field` 不设 control_type，只保留 data_type。

## 一、两层架构

| 层 | 职责 | 存什么 | 复用 |
|---|---|---|---|
| 字段字典（05 crf_field） | 字段「是什么」 | 249 字段 + 上下级 + 码表引用 + 外键 + 条件必填 + data_type | 纯数据 |
| 表单模板（复用 AUP formTemplate） | 字段「怎么呈现」 | Section/SubSection/Field + type(题型) + options/dictKey + showWhen | aup-template/edit |

## 二、复制 AUP 模式为 NHP 专用（不共享组件）

**原则：复用 AUP 的「模式/结构」，但把代码复制成 NHP 专属组件，不与 AUP 共享同一组件**，避免 NHP 的改动影响 AUP。

| AUP 源文件 | 复制为 NHP 专用 | 说明 |
|---|---|---|
| `schema/formTemplate.ts` | `features/nhp/schema/formTemplate.ts` | Section/SubSection/Field 三级 + type/options/dictKey/showWhen/config |
| `schema/typeRegistry.ts` | `features/nhp/schema/typeRegistry.ts` | 22 题型，可增 NHP 专属题型 |
| `pages/admin/AupTemplateEditor.tsx` | `features/nhp/pages/admin/NhpTemplateEditor.tsx` | 题型菜单、选项来源、条件编辑器 |
| `components/FormField.tsx` | `features/nhp/components/NhpFormField.tsx` | 题型渲染组件（各自独立） |

## 三、字段字典 → 表单模板 连锁关系自动生成

| 字段字典列 | 表单模板属性 | 连锁效果 |
|---|---|---|
| 数据域 D1-D10 | Section（code=D1, label=供体猪域） | 层级 |
| 子模块 D1.01 | SubSection（code=D1.01, label=个体档案） | 层级 |
| 字段 donor_id | Field（fieldKey=D1.01.001, label=供体猪ID） | — |
| 码表引用（码表FARM） | `dictKey = FARM` | 自动挂码表选项 |
| 外键（关联 D3） | `cascade` / `select` | 自动级联选择 |
| 条件必填 | `showWhen` | 自动条件连锁 |
| data_type | `type` 默认题型 | **仅默认，可自由改** |
| 必填 | `required` | 直连 |
| 单位 / 说明 | `config.unit` / `description` | 直连 |

## 四、data_type → 默认题型（仅建议，编辑器可改）

| data_type | 默认题型 |
|---|---|
| 字符 | text |
| 文本 | textarea |
| 数值 | number |
| 日期 / 日期时间 / 时间 | date |
| 枚举（有码表） | select（dictKey 指向码表） |
| 枚举多选 | checkbox（dictKey 指向码表） |

> 用户在 aup-template/edit 里可把任何字段改成任意 22 题型之一（如把某个枚举改成单选按钮、把「监护序列」改成 repeatGroup、加 file/image 上传）。题型选择是表单设计决策，不焊死在字典。

## 五、工作流

```
249 字段字典（05）→ 自动生成「初始 CRF 表单模板」（Section/SubSection/Field + 连锁自动挂好）
                 → aup-template/edit 里自由配置 题型/选项/题目/条件
                 → 保存为可发布 CRF 表单（V1.0 冻结）
```
