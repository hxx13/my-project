## 三、四条铁律（违反即返工）

1. **动表必留痕**：任何「建表 / 加列 / 改列 / 删列 / 改数据类型 / 改单位 / 改码表 / 改必填」的操作，**动手前**先在《变更日志.md》追加一条记录，**同步**更新 03/04 里对应的字段条目。日志与字段表不一致 = 违规。

2. **建表必须四步走**：建表 / 改表必须走「双 SQL 迁移 + 启动链注册 + Java 适配」完整链路（详见 01），**禁止**直接连数据库手工改表。

3. **值必须对表**：字段英文名（即 DB 列名）、数据类型、单位、必填、码表引用，必须与 03/04 一致；身份 / 权限必须与 02 一致。不得擅自发明新值、新码表、新角色。

4. **导入必全量**：从 xlsx / docx 等源文件导入或转写内容时，**禁止丢弃任何列或 sheet**，宁可全留不可删；拿不准的列 / sheet 也原样保留并标注，不得自行判断「不重要」而删。（2026-08-20 曾因丢弃 PI 校对列与多张 sheet 导致字段含义偏离，故立此条。）

## 四、怎么查

- 按数据域查字段：打开 03，找对应域（D1~D10）。
- 按字段编码查：`D1.02.003` → D1 域、02 子模块、003 字段。
- 按英文名 / 列名查：字段名（英）即数据库列名，如 `donor_id`、`tx_id`。
- 查某个枚举能取什么值：打开 04 的码表，按码表编码（如 `BREED`）查。
