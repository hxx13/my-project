# 01-建表要求与规范

> 建表 / 改表是**不可逆且高风险**操作。所有数据库结构变更必须走完整四步链路，任何一步都不能省。本文件是唯一规范。

## 一、建表四步走（强制链路）

任何「新建表、加列、改列、删列、加索引、改码表种子」都必须完成以下四步，缺一不可。

### 步骤 1：双 SQL 迁移（两个位置都要写）

本项目 SQL 迁移是「双轨」：一份归档、一份启动链幂等，**两份同源、内容一致**。

| 位置 | 命名 | 作用 | 特点 |
|---|---|---|---|
| `common/schema/` | `V{YYYYMMDD}{seq}__{name}.sql` | Flyway 版本化归档 | 记录历史，只执行一次 |
| `src/main/resources/db/` | `bootstrap-{name}.sql` | 启动链自动幂等执行 | `CREATE TABLE IF NOT EXISTS` + `information_schema` 逐列检查，重复执行无副作用 |

- 示例：`common/schema/V20260815__person_identity.sql` ↔ `src/main/resources/db/bootstrap-person-identity.sql`
- 两份文件必须**同源同义**；加列用幂等写法（`information_schema.COLUMNS` 检查后 `ALTER TABLE ... ADD COLUMN`）。

### 步骤 2：启动链注册

`bootstrap-*.sql` 由 `EmbeddedTwinSystemCoreDdlBootstrap` 在启动时自动幂等执行。新增 bootstrap 文件后，确认其被启动链扫描执行（无需手动跑库）。

### 步骤 3：Java 适配

新表 / 新列需同步实体（entity）、Mapper、Service / Controller，与既有模块结构一致。

### 步骤 4：验证 + 留痕

执行后验证表结构落库正确，并在《变更日志.md》记录本次变更。

## 二、表命名规范

- 表名、列名一律 `snake_case` 小写英文。
- 建表统一 `CREATE TABLE IF NOT EXISTS` + `ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='中文说明'`。
- 每列必须带 `COMMENT`（中文说明，落库即文档）。
- 主键统一 `id BIGINT NOT NULL AUTO_INCREMENT PRIMARY KEY`。
- 时间戳统一 `created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP`（有更新语义的再加 `updated_at`）。
- 索引命名：唯一键 `uk_` 前缀，普通索引 `idx_` 前缀。
- 逻辑删除 / 启用统一 `active TINYINT NOT NULL DEFAULT 1`。

## 三、字段定义规范（对齐 03）

字段英文名（即 DB 列名）必须与《03-字段总目录.md》中「字段名（英）」一致，禁止自造。字段的标准元数据有：

| 元数据 | 说明 |
|---|---|
| 字段编码 | 如 `D1.02.003`（域.子模块.序号），只作字典追溯，不落库 |
| 字段名（英） | DB 列名，snake_case |
| 数据类型 | 字符 / 文本 / 数值 / 日期 / 枚举 / 布尔… 决定 SQL 类型 |
| 单位 / 格式 | 如 `mg/kg`、`YYYY-MM-DD` |
| 必填 | 是 / 否 / 条件（条件必填在「说明」写清触发条件） |
| 取值 / 码表 | 枚举字段指向《04》的码表编码；外键字段标 `外键`；自增 / 编码字段标 `编码规则` |
| 采集时点 | TP-01~TP-12 或具体事件 |

### 数据类型 → SQL 类型映射（本档案确立的约定，后续建表统一遵循）

| 字典类型 | SQL 类型 |
|---|---|
| 字符 | VARCHAR(n)（编号 / 主键类通常 VARCHAR(64)） |
| 文本 | TEXT |
| 数值 | DECIMAL / INT（按单位精度） |
| 日期 | DATE |
| 枚举 | VARCHAR(64)（取值受《04》码表约束） |
| 布尔 / 开关 | TINYINT |

## 四、禁止事项

- ❌ 禁止直接连数据库手工 `ALTER / CREATE / DROP`（必须走四步走）。
- ❌ 禁止改字段英文名（列名）后不更新 03、变更日志。
- ❌ 禁止在未读 03 的情况下「凭感觉」建字段。
