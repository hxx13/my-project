# 04-码表与编码规则

> 码表是枚举字段的取值定义；**码表变更必须走版本流程，禁止直接改值**。改码表同步更新本文件与《变更日志.md》。

## 一、码表（取值域）

| 码表编码 | 码表名 | 取值 | 取值说明 |
|---|---|---|---|
| FARM | 养殖基地 | SH=上海SPF共建基地 | 可扩展其他体系基地 |
| CENTER | 动物/临床中心 | SJ=交大动物中心共建平台 | 附属医院临床阶段扩展 RJ/XH/HS 等 |
| BREED | 猪品种 | 巴马小型猪 / 五指山小型猪 / 其他 | 以实际种群为准 |
| EDIT | 编辑组合 | GTKO / GTKO-CMAH-KO / GTKO-CMAH-B4GAL-KO / 多敲+人源转入 | 组合码=敲除序列+转入序列，全平台统一命名 |
| PATHOGEN | 供体指定病原清单 | PERV-A/B/C、PCMV、PCV2、PCV3、PCV4、HEV、弓形虫、布鲁氏菌等 | SPF/DPF 清单版本化，随监管要求更新 |
| NHP_PATH | NHP 病原清单 | B病毒、结核分枝杆菌、SIV、SRV、STLV、沙门氏菌、志贺氏菌 | 检疫期排查 |
| ORG | 器官 | K=肾 / H=心 / L=肝 / Lu=肺 | 扩器官时扩码 |

| PROC | 术式 | 原位替代 / 辅助性 / 异位 / 细胞组织灌注 | 按器官细化 |
| IMMU | 免疫方案 | IND-CD154 / IND-CD40 / MTX-TAC-MMF 等方案编码 | 方案库版本化，含剂量与调整规则 |
| SAMPLE | 样本类型 | EDTA全血/血清/血浆/PBMC/尿液/粪便/组织/灌洗液 | 组织按器官码扩展 |

| AE | 事件类型 | 超急性排斥/急性体液排斥/急性细胞排斥/感染/血栓性微血管病/出血/其他 | 异种移植事件分类（适配版） |
| GRADE_AE | 事件分级 | 1轻度/2中度/3重度/4危及生命/5死亡 | 参照 CTCAE 适配 |
| ENDPOINT | 终点类型 | 计划终点/人道安乐死/死亡 | — |
| CAUSE | 终点原因 | 排斥/感染/TMA/出血/手术并发症/移植物失功/其他 | 与剖检病理互证 |
| VER | 版本对象 | DICT字典/PANEL/CRITERIA放行标准/PROTOCOL方案 | 全部标准版本化留痕 |
| DRUG_IS | 免疫抑制药物 | TAC=他克莫司 / MMF=吗替麦考酚酯 / MP=甲泼尼龙 / BAS=巴利昔单抗 / ATG=抗胸腺细胞球蛋白 / RAPA=雷帕霉素 / 抗CD154单抗 / 抗CD40单抗 | 药物编码版本化；新药入表走版本流程 |
| ROUTE | 给药途径 | PO=口服 / IV=静脉 / IM=肌注 / SC=皮下 / IA=动脉灌注 | — |

| LIVER_APP | 肝脏外观评分 | A=均匀红润质软 / B=局部花斑 / C=广泛淤血暗紫质硬（判不合格） | 评分细则请肝脏PI定稿后版本化 |

## 二、编码规则（四级 ID 体系）

| 编码对象 | 编码格式 | 示例 | 段含义 | 规则说明 |
|---|---|---|---|---|
| 供体猪 ID | DON-{基地}{年}-{序号4} | DON-SH26-0031 | 基地码(SH)+出生年(26)+个体序号 | 终身唯一；编辑组合变化不变码，谱系见 D1 谱系表 |
| 受体猴 ID | RCP-{中心}{年}-{序号3} | RCP-SJ26-007 | 中心码(SJ)+入组年+序号 | 入组即赋码；未移植的预筛猴也赋码（用于配对库） |
| 配型记录 ID | XM-{DONOR}-{RECIP} | XM-SH26-0031-SJ26-007 | 供体-受体对 | 同一对可有多条（不同检测方法/时点），加后缀 -01/-02 |
| 移植事件 ID | TX-{中心}{年}-{序号3} | TX-SJ26-003 | 中心+年+移植例序号 | 一例一次移植唯一；二次移植另赋码并关联首诊 |
| 随访记录 ID | FU-{TX}-{时点} | FU-SJ26-003-TP07 | 移植事件+时点码 | 纵向随访序列；同一时点一条主记录，事件触发随访挂 TP10 |
| 不良事件 ID | AE-{TX}-{日期}-{序号2} | AE-SJ26-003-260915-01 | 移植事件+发生日期+当日序号 | 事件触发即赋码；排斥/感染/血栓等均入 AE 序列 |
| 免疫方案 ID | REG-{TX}-{序号2} | REG-SJ26-003-01 | 移植事件+方案序号 | 一例多方案（诱导/维持/挽救）连号 |
| 用药记录 ID | MED-{REG}-{序号4} | MED-SJ26-003-01-0007 | 方案+给药序号 | 每次给药一条，执行人同步记录 |
| 血药浓度监测 ID | LVL-{TX}-{日期}-{序号2} | LVL-SJ26-003-260912-01 | 移植事件+采血日期+序号 | 采血时间须记录以判定谷/峰浓度 |
| 麻醉记录 ID | ANES-{TX} | ANES-SJ26-003 | 移植事件 | 一台手术一条麻醉主记录 |
| 病理记录 ID | PATH-{TX}-{时点}-{序号2} | PATH-SJ26-003-TP05-01 | 移植事件+时点码+序号 | 一次取材一条；剖检逐器官连号 |
| 心脏模块记录 ID | HX-{TX} | HX-SJ26-003 | 移植事件 | 一移植事件一条心脏模块主记录 |
| 灌注记录 ID | PERF-{DON}-{日期} | PERF-SH26-0031-260910 | 供体+灌注日期 | 体外肝灌注事件唯一 |
| 样本 ID | SMP-{TX}-{时点}-{样本类型}-{分管2} | SMP-SJ26-003-TP07-EDTA-03 | 移植事件+时点码+样本类型码+分管号 | 采血即赋码；分管规则：同管同型连号 |
| 检测委托单 ID | TST-{实验室}{年月}-{序号4} | TST-LB2609-0112 | 受托实验室码+委托年月+序号 | 一单可含多 panel 项目；与样本 ID 多对多 |
| 检测结果 ID | RS-{TEST_ID}-{项目码} | RS-LB2609-0112-PERVA | 委托单+检测项目码 | 结果行级唯一；附方法学版本号 |
| 时点编码 | TP{两位} | TP07 | 见下方时点表 | 全平台统一天数锚点，允许多中心对齐 |
| 器官编码 | ORG-{1位} | ORG-K | K=肾 H=心 L=肝 Lu=肺(2位) | 供体器官出厂判定按器官编码归档 |
