# 08-前端可视化设计（NHP CRF/EDC）

> 状态：**设计态**。本文件定义 NHP 业务前端三个入口/页面的版式，全部**在真实现有页面上下文中设计**（带顶栏/侧栏等周边元素），避免实装偏差。
>
> 可视化依据（2026-08-20 浏览器实测 `localhost:5173`）：
> - 首页顶栏 `features/portal/PortalHeader.tsx`
> - 后台布局 `layouts/AdminLayout.tsx`（侧栏分组）
> - 字典管理范本 `features/aup/pages/admin/AupDictPage.tsx`
> - 文件管理范本 `pages/AdminFileTemplatesPage.tsx`
>
> **可视化原型**：`原型/NHP-CRF-EDC前端设计原型.html`（单文件三个标签页，复刻真实顶栏/侧栏配色，浏览器直接打开可看）。

## 一、参考版式盘点（实测）

### 1.1 首页顶栏（PortalHeader）

深色 sticky 顶栏 `h-16`，`bg-[#0f172a]/95`，布局：

```
[交大logo]  首页  模型资源▾  新闻动态▾  关于我们▾        [手机版] [头像 姓名▾]
```

- 导航项数据在 `useNavEntries` 硬编码：`首页 / 模型资源 / 新闻动态 / 关于我们`
- 每个导航项支持 `children`（下拉）：「关于我们」下拉里现有「填写计划书 → /aup/fill」（AUP 入口范本）
- 下拉样式：`bg-[#1e293b]` 深色卡片，`label + desc` 两行

### 1.2 后台布局（AdminLayout）

左侧固定侧栏 + 右侧内容区，侧栏为**可折叠分组导航**：

```
[上海医学院logo]  门户首页  仪表盘
[后台工作台]
[搜索页面… Ctrl K]  [收起侧栏]
── 收藏
── 消息
── 常用（文件模板库 / AUP 计划书 / 实验动物订购）
── 学生审核 (13)
── 资产与运维（…文件模板库 / 填报报表管理 / 填报中心 / AUP 计划书）
── 门禁、元数据与环境
── 系统与安全
── 组织与通知
── 报修与物资领用 (7)
── AI 实验室
── ARO 房间与联动
```

内容区顶：`收起侧栏 | 返回上一页 | 搜索 | 页面标题 + [标准][本页帮助][管理侧边栏文件夹] | 用户`

### 1.3 字典管理范本（AupDictPage）——字段/码表管理复用

「分类（文件夹）→ 字典 → 字典项」两层结构，双栏：
- **左栏**：按分类分组的字典列表（可折叠，显示项数 + 字典键）
- **右栏**：选中字典的项表格（序 / 内部值唯一 / 展示文本 / 操作：上移↓下移✎删除），＋新增项
- 自带 scoped 设计语言 `.aup`（CSS 变量 `--p:#002FA7` 主蓝、白卡片、圆角 12px 表格）

### 1.4 文件管理范本（AdminFileTemplatesPage）——文件管理复用

单页表格：`[上传模板]` 按钮 + 文件表格（文件名 / 大小 / 上传时间 / 操作：下载·删除）。

## 二、设计一：首页顶栏入口

**在顶栏新增顶级导航「NHP 研究」**，位于「新闻动态」与「关于我们」之间；下拉三个入口，样式复用现有 `NavDropdown`。

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ [交大logo]  首页  模型资源▾  新闻动态▾  NHP研究▾  关于我们▾   [手机版] [头像▾] │
│                                     │                                          │
│                     ┌───────────────┴────────────────────┐                     │
│                     │ CRF 数据采集        研究数据录入入口  │                     │
│                     │ 数据字典（字段/码表）  字段与码表管理   │                     │

| 项 | 值 |
|---|---|
| 导航 label | `NHP 研究` |
| 下拉项 | CRF 数据采集 → `/nhp/fill`（AuthGuard，后续）；数据字典 → `/console/admin/nhp-dict`；文件管理 → `/console/admin/nhp-files` |

## 三、设计二：字段/码表编辑管理页

**复用 AupDictPage 的双栏 + `.aup` 设计语言**，把「分类→字典→字典项」映射为「数据域→字段→字段元数据/码表项」。

```
┌──────────────┬─────────────────────────────────────────────────────────────────┐

│ ▾ NHP 研究    │  │ 搜索字段… [查询]          共 249 字段 · 13 域   [+新建字段]  │ │

│  ·文件管理    │  │ │ 字段列表(左)     │ 字段详情(右)                          │ │ │
│              │  │ │ ▾D1 供体猪域(29) │ ── 字段元数据（12列）──              │ │ │
│              │  │ │  ▾D1.01个体档案  │ 字段编码 D1.01.001                    │ │ │
│              │  │ │   ·供体猪ID      │ 字段名(英) donor_id  字段名(中) 供体猪ID │ │ │
│              │  │ │   ·基地编码      │ 类型[枚举▾] 单位[—] 必填[是▾]          │ │ │

**结构决策**（对照 AupDictPage）：
- 左栏「数据域 D1-D10 → 子模块 → 字段」三级分组（复用 `.aup-group` 折叠），替代 AupDictPage 的「分类→字典」
- 右栏字段详情 = **03 字段表的完整 12 列**（字段编码/中/英/类型/单位/必填/码表/时点/采集方/说明/PI校对/校对意见），可编辑
- 码表项子表：仅当字段 `取值/码表` 指向码表时展开，复用 AupDictPage 的「序/内部值/展示文本/操作」
- 顶部按钮 `＋新建字段`、行内「冻结」操作对接 05 的冻结状态机

## 四、设计三：后台记录管理页（填写的文件）

**复用 AupListPage（`/console/admin/aup`）的卡片列表模式**——不是上传文件，而是管理已填写的 CRF 记录：视图切换、状态筛选、排序、卡片列表（编号/供体/受体/移植类型/流程阶段/查看删除快照）。

```
┌──────────────┬─────────────────────────────────────────────────────────────────┐
│ 后台侧栏       │  NHP CRF 记录                        [标准] [本页帮助]        │
│              │  ┌─────────────────────────────────────────────────────────────┐ │
│ ▾ NHP 研究    │  │ [▦卡片][☰列表] [草稿][已提交][已冻结] 与我相关 排序▾ 筛选▸ 共12条│ │
│  ·数据字典    │  │ ┌────────────────────────────────────────────────────────┐ │ │
│  ·记录管理    │  │ │ 心脏移植 NHP CRF              编号 TX-SJ26-003         │ │ │
│              │  │ │ 供体猪 DON-SH26-0031  受体猴 RCP-SJ26-007               │ │ │
│              │  │ │ 移植类型 部分心脏异位移植  术者 张XX                     │ │ │
│              │  │ │ [填写]→[复核]→[冻结]→[完成]        审查中  [查看][删除]  │ │ │
│              │  │ └────────────────────────────────────────────────────────┘ │ │
│              │  └─────────────────────────────────────────────────────────────┘ │
└──────────────┴─────────────────────────────────────────────────────────────────┘
```

**结构决策**（对照 AupListPage）：
- 工具栏：视图切换（卡片/列表）、状态筛选（草稿/已提交/已冻结）、与我相关、排序、筛选、计数
- 卡片：标题 + 编号、供体/受体/移植类型/术者、流程阶段管道（填写→复核→冻结→完成）、查看/删除/快照
- 数据源对应 06 的 `crf_record`（表单实例）+ `crf_subject`（受试者）

## 五、后台侧栏归属

新增侧栏分组 **「NHP 研究」**（位置：`常用` 分组之后），含两个页面：

```
▾ NHP 研究
  · 数据字典    → /console/admin/nhp-dict
  · 记录管理    → /console/admin/nhp-records
```

## 六、设计决策清单

| # | 决策 | 推荐 |
