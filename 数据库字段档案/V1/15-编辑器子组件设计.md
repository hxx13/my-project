## 三、每个子组件详细设计

### 3.1 SectionTree.tsx（左栏树）
- **Props**：`sections`、`selectedFieldKey`、`selectedSectionCode`、`onSelectField(key)`、`onSelectSection(code)`、`onAddSection()`、`onRemoveSection(code)`
- **状态**：无（纯展示 + 回调），折叠态可用内部 `useState`
- **行为**：渲染 `Section → SubSection → Field` 三级树；Section/SubSection 可折叠；字段选中高亮；Section 行内「＋」添加字段
- **源码**：`AupTemplateEditor.tsx` 主组件 1709 起，左侧 aside 树渲染

### 3.2 FieldEditorPanel.tsx（右栏编辑）
- **Props**：`field: FormField`、`onChange(patch: Partial<FormField>)`
- **行为**：编辑 label / description / required；按 `field.type` 分发到 `OptionsEditor`（有选项的题型）/ `StructEditor`（嵌套题型）/ `ShowWhenEditor`（所有字段的「高级设置」）
- **源码**：`FieldEditorInline` 1111-1578

### 3.3 TypeMenu.tsx（题型菜单）
- **Props**：`onSelect(type: FieldType)`
- **行为**：网格弹窗，按 `typeRegistry` 的 `group` 分组（基础输入/选择类/结构化/上传类/特殊装饰），点击选中回传
- **数据源**：`features/nhp/schema/typeRegistry.ts`（已建，19 题型）
- **源码**：`TypeMenu` 599-645

### 3.4 OptionsEditor.tsx（选项编辑）
- **Props**：`options: FieldOptions`、`dictKey?: string`、`onChange({ options, dictKey })`
- **行为**：两个来源二选一——「手动填写」（增删改选项行，含 value/label/group/fixed）或「引用码表」（下拉选 `dictKey`，选项来自码表）
- **码表数据源**：需对接 NHP 码表接口（04 的码表编码，如 FARM/BREED）
- **源码**：`OptionsEditor` 646-796

### 3.5 ShowWhenEditor.tsx（条件连锁编辑）
- **Props**：`showWhen: ShowWhen | null`、`fieldCatalog`（buildFieldCatalog 结果）、`onChange(showWhen)`
- **行为**：选目标字段（下拉，来自 fieldCatalog）→ 选运算符（equals/notEquals/contains/notContains/notEmpty/empty）→ 选比较值（若运算符需要，下拉来自目标字段的选项）
- **源码**：`ShowWhenEditor` 476-598；配套 `buildFieldCatalog` 164、`buildRevealMap` 211

### 3.6 StructEditor.tsx + ChildFieldList.tsx + ColumnOptions.tsx（结构化字段）
- **Props**：`field: FormField`（type ∈ table/group/repeatGroup）、`onChange(config)`
- **行为**：
  - `table`：编辑列（每列是 FormField），用 `ColumnOptions`（797）编辑列
  - `group` / `repeatGroup`：编辑子字段列表，用 `ChildFieldList`（1057）+ `ChildFieldRow`（852）
- **源码**：`StructEditor` 1579-1708

## 四、与 store 的对接（约束）

- 所有子组件是**受控组件**：props 传入当前值，改动通过 `onChange` 回调，最终由 `useTemplateEditor` 的 actions（`updateField` 等）改状态。
- 子组件**不直接 import zustand store**，只通过 props 收发，便于复用与单测。
- 编辑器壳 `NhpTemplateEditor.tsx` 负责把 store 状态分发给各子组件。

## 五、实现顺序建议

1. 先抽「工具函数」到 `store/`（纯函数，可直接从 AUP 行号 84-256 复制改写）。
2. 再建 `TypeMenu` + `OptionsEditor`（最简单，无嵌套）。
3. 再建 `ShowWhenEditor`（依赖 buildFieldCatalog）。
4. 最后建 `StructEditor` + `ChildFieldList`（最复杂，嵌套字段）。
5. `SectionTree` 和 `FieldEditorPanel` 贯穿始终，随其它组件逐步完善。
