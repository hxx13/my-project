## 二、建表四步走（硬约定，承接 01）

每个表必须走完整四步，**禁止直连库**：

### 步骤 1：双 SQL（两个位置都写，同源同义）

| 位置 | 命名 | 作用 |
|---|---|---|
| `common/schema/` | `V{YYYYMMDD}{seq}__{name}.sql` | Flyway 版本化归档 |
| `src/main/resources/db/` | `bootstrap-{name}.sql` | 启动链幂等执行（CREATE TABLE IF NOT EXISTS + information_schema 逐列检查） |

建议命名（按批）：
- `V20260821__nhp_meta_tables.sql` / `bootstrap-nhp-meta.sql`（元数据 11 张）
- `V20260821__nhp_data_tables.sql` / `bootstrap-nhp-data.sql`（数据 13 张）
- `V20260821__nhp_import_table.sql` / `bootstrap-nhp-import.sql`（导入 1 张）

### 步骤 2：启动链注册（最容易漏）

在 `src/main/java/com/example/demo/common/bootstrap/EmbeddedTwinSystemCoreDdlBootstrap.java` 的 `runScript` 列表里**显式加一行**：

```java
total++; if (runScript("db/bootstrap-nhp-meta.sql", ctx)) success++;
total++; if (runScript("db/bootstrap-nhp-data.sql", ctx)) success++;
total++; if (runScript("db/bootstrap-nhp-import.sql", ctx)) success++;
```

> 不是自动扫描 classpath，是硬编码列表。漏注册 = 表不建，且静默无报错。

### 步骤 3：Java 适配（模块结构）

```
src/main/java/com/example/demo/modules/nhp/
├── entity/        # 每表一个实体（MyBatis）
├── mapper/        # 每实体一个 Mapper（MyBatis）
├── service/       # 业务服务
├── controller/    # REST 控制器
├── dto/           # 请求/响应 VO
└── config/        # 种子/引导（如需）
```

参考 AUP 模块（`modules/aup/`）的 entity/mapper/controller 分层，NHP 同构复制。

## 三、REST API 端点（7 个 Controller）

统一前缀 `/api/nhp/...`，响应 `Result<T>` = `{code, success, message, data}`。

## 四、关键实现注意

1. **字段值 upsert（NhpRecordController）**：一次保存写多条 `crf_record_value`（含 collected_at / source_type / source_ref），同时写 `crf_data_audit_log`（before/after + change_reason），三者同事务。来源列落在 record_value，不落审计表。
2. **取号（NhpIdController）**：`crf_sequence` 用 `UPDATE ... SET next_value = next_value + 1` 原子递增，防并发重号。
3. **冻结（NhpFieldController）**：字段冻结触发 06 的物化宽表生成，走四步走，不是简单改 status。
4. **码表版本（NhpCodelistController）**：码表项变更走版本流程，禁止直接改值（04 规定）。
5. **孤儿表处理**：crf_study / crf_center / crf_visit / crf_validation_rule / crf_dag / crf_dag_user / crf_form_role / crf_id_rule 是「种子/配置表」，走 bootstrap 种子 + 管理端配置，不逐条开 REST CRUD（避免死表）。

## 六、对底层代码架构的影响（承接 13）

- 后端同构复制 AUP 的 entity/mapper/service/controller 分层，**不复用 AUP 的 Java 类**（避免 NHP 改动影响 AUP）。
- 前端 7 个 Controller 对应前端 `api/nhp/` 下的 7 个 api 文件。
- 建表四步走是「不可逆写库」，动手前需再确认一次。
