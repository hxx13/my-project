## 二、执行纪律（铁律，违反即错位）

1. **双 SQL 四步走**：每个建表/改表 = ① Flyway 归档 `common/schema/V*.sql` + ② bootstrap 幂等脚本 `src/main/resources/db/bootstrap-nhp-*.sql` + ③ 启动链 `EmbeddedTwinSystemCoreDdlBootstrap` 注册 + ④ Java entity/mapper 适配。**四步缺一即错位**。
2. **禁止直连数据库、禁止漏注册启动链**（改表必须走 SQL 迁移，不能手改库）。
3. **自动建表**：SQL 迁移文件写好并注册后，必须自动连接数据库执行迁移，不让用户手动操作。
4. **迁移编号从 V20260821039 起**（V25~38 是计划里已规划的编号，尚未建；V24 是现有最新）。顺序执行 V25 → V26 → … → V38，每个同步产出 bootstrap + 注册 + Java。
5. **低可信度域（D6/D9/D10）先建 DRAFT 骨架**：字段 `status=DRAFT` 不进 FROZEN，冻结权交 PI 校对流。
6. **不擅自 kill 进程 / 停服务**。
7. 前端类型检查用 `npx tsc -b --noEmit`（裸 `tsc --noEmit` 恒假绿）。

## 五、易错点清单（三轮复核踩过的坑，别重踩）

1. **schedule 是两列**（`event_anchor` + `frequency`），**没有 `repeat_flag`**（repeat 由 frequency≠ONCE 表达）。
2. **`crf_record` 已有 `visit_instance_id`**，只加 `atom_id` + `transplant_id`，不要重复加 visit_instance_id。
3. **`crf_field` 加 `concept_code`，不加 `timepoint`**（时点是访视/原子属性，非字段属性）。
4. **`role` 不用加**——已在 `crf_form_field` 且 JSON 已正确填充（222 VALUE / 15 PK / 12 FK / 0 DERIVED）；只补 DERIVED（pairing_score 等）。
5. **`crf_sequence` 键泛化 `(id_type, scope_key)`**，不是 center_code+year。
6. **scope_key 拼法**：DON=`{base}|{year}`、RCP/TX=`{center}|{year}`、MED=`{reg}`、SMP=`{tx}|{tp}|{type}`、PATH/FU=`{tx}|{tp}`、AE/LVL=`{tx}|{date}`、XM=`{donor}|{recip}`、TST=`{lab}|{yearmonth}`、REG=`{tx}`、PERF=`{don}|{date}`。
7. **`buildCode` 未解析占位符抛异常**，不静默返回字面量；占位符全集含 `{base}/{center}/{DONOR}/{DON}/{RECIP}/{TX}/{REG}/{TEST_ID}/{TP}/{日期}/{年月}/{样本类型}/{实验室}/{项目码}`。
8. **DON 用 FARM 基地码、RCP/TX 用 CENTER 中心码**，分码表，勿拍平成 center。
9. **FU/XM 补 seq、TP 码统一无横线 `TP01`**（存量 `TP-01`→`TP01` 迁移）。
10. **排斥分级权威在 D8**（`rej_grade`），D5 通过 `rejection_ref` 引用，不重复存。
11. **概念库**：`crf_concept` + `crf_field.concept_code`，肌酐/凝血等指标只定义一次 concept，多域 field_code 复用。
12. **序列聚合查询 `listSeries` 必须随概念库同步落地，不后置**（否则前端趋势曲线画不出）。
13. **verdict 维度**：`crf_field` / `crf_codelist_item` 加 `verdict`（CONFIRM/MODIFY/DELETE/QUESTION）+ `verdict_note`；校对工作流"第二轮商议"用 `review_round` 承载，不扩状态机。
14. **数据质量中心**：`crf_quality_event` + 4 类检测器（OUTLIER/DEVIATION/TAT_OVERDUE/COC_BROKEN）+ 月报聚合。
15. **对象状态机 + 访视编排**：`crf_subject.lifecycle_stage`（SCREENING/MATCHING/POST_TX/ENDPOINT）+ `crf_visit_plan`（visit_id×atom_id 编排）。
16. **`crf_transplant` 不含 intraop_samples**（归 crf_sample）；`crf_test_order` 要加 `sample_id`（补样本→委托单→结果溯源链）。
17. **`crf_drug_level` 归属 `regimen_id`**（浓度挂方案非移植），tx_id 冗余可空。
18. **D8 的 IHC/IF 拆 1:N 子表**（`crf_pathology_ihc`/`crf_pathology_if`），不压 JSON。
19. 实体表 DDL 里 **码表标注要对齐 Excel 29 个**（尤其 `organ_function_grade`→码表 GRADE、`change_reason`→码表 DOSE_ADJ）。
